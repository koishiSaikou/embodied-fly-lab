# 蘑菇体局部学习

这是本机开发中的第一版局部神经可塑性实验，默认关闭。启用后，真实 KC 放电与外部教学信号会改变所选 KC→MBON 连接的临时增益。这与“行为”面板里的两个气味偏好数值是两套独立记忆；不是整个大脑已经学会自然觅食。

## 怎么开始

1. 正常结束并保存旧实验，再用原启动入口打开新版多感官实验场。运行中的旧进程不会自动获得新功能。
2. 在右侧选择“局部学习”，保留默认 `KCg-m → MBON01`，点击“检查目标”。本地 v783 数据应显示 2,189 个候选 KC、2 个 MBON、1,865 条既有正连接；只有存在连接的 1,865 个 KC 实际参与这些边的更新。
3. 勾选“启用局部学习模块”，保留“允许突触增益继续学习”和气味 KC 输入桥，点击“应用配置”。观察已应用设置与脑工作进程的实际读出，不要把尚未应用的草稿当成运行配置。
4. 教学来源先选“手动”：让果蝇感受到一种气味时，点击 `0.5` 或 `1`，使该气味诱发的 KC 活动与教学门控配对。按钮是持续门控，结束配对必须点击 `0 · 停止教学`。
5. 关闭“允许突触增益继续学习”并应用，可冻结权重，用已学增益继续观察。先固定其他刺激、递质增益、场景和输入，再比较配对气味与另一气味的 MBON 响应。观察指标包括变化边数、最小/平均增益，以及两个 MBON 最近一块的实际放电率。
6. 结束并保存实验。历史页导出 ZIP、其他人导入后选择“最终配置”新开实验，可以沿用已学突触因子；选择“初始条件”则从初始因子开始，重放已应用设置事件。

也可选择“糖接触”教学来源：实际味觉开关启用且检测到甜味时，用门控后的甜度作为教学强度。这里的“糖接触”是外部教学代理，不代表已经模拟多巴胺神经元释放过程。手动值在此模式下不替代糖接触输入。

暂停期间可以应用设置或重置并获得权重状态确认，脑和身体时钟保持不变；此时 MBON 放电读数来自暂停前最近一个积分块。重新运行才会产生新放电。冻结时资格迹仍随活动演化，重新允许学习时可能使用尚未衰减的迹。

## 三个容易混淆的开关

| 操作 | 含义 |
| --- | --- |
| 关闭“允许突触增益继续学习” | 冻结因子；模块启用时仍使用已学因子和气味输入桥 |
| 关闭模块总开关 | 绕过已学因子和本模块气味输入；保留内存里的学习结果，再开启可继续使用 |
| 重置局部突触记忆 | 因子恢复 1，资格迹与学习累计归零；不会倒退脑时间、身体状态或随机数 |

“行为”中的清除气味记忆只清外置价值表，不清这里的突触因子。更换 KC/MBON 类型会重新建立局部集合并清除对应学习；更换气味编码种子或稀疏比例保留因子，但清除资格迹。提高最小因子若会抬高已有记忆，会拒绝应用，需先明确重置。

## 参数与实际算法

| 参数 | 默认值 / 范围 | 作用 |
| --- | --- | --- |
| 学习率 | 0.1 / 0–1 每模型秒 | 配对活动引起增益下降的速度；使用模型时间 |
| 资格迹时间常数 | 1 / 0.05–10 秒 | KC 最近放电留下的短期痕迹衰减时间 |
| 最小突触因子 | 0.2 / 0.05–1 | 限制局部减弱幅度 |
| KC 外源输入 | 80 / 0–200 Hz | 气味输入桥的最高附加 Poisson 率，保留不应期门控 |
| 编码比例 | 0.1 / 0.01–0.25 | 每种气味对应的稀疏 KC 比例；两种模式可能重叠 |
| 气味编码种子 | 1 / 32 位非负整数 | 通过 ID 的确定性 SHA256 排序选择模式，不额外消耗模型 RNG |

每个脑积分块结束，用**夹持干预后的实际 KC 放电计数**更新资格迹和因子：

```text
e = clip(exp(-dt / tau) * e + 0.05 * KC_spike_count, 0, 1)
factor = clip(factor - learning_rate * teaching * e * dt, min_factor, 1)
W_effective[post, pre] = W_transmitter[post, pre] * factor
```

`dt` 是本块实际模型秒；默认控制块为 20 ms。这里使用块末计数的近似资格迹，改变的因子从下一块生效。只实现教学门控的局部长期减弱（LTD），没有负奖励增强、LTP、精确脉冲时序规则或新增连接。已经进入其他神经元的延迟电流不会被回滚。

先应用已有递质来源增益，再乘所选边的学习因子；其他边和原符号保留。模块关闭或因子全为 1 时直接使用递质模块的原张量。原连接表、磁盘稀疏缓存、上游 LIF 方程不修改。

## 数据身份与科学边界

默认目标来自本地模型顺序注释的 `cell_class=Kenyon_Cell / MBON` 和精确 `cell_type`，再与真实 CSR 正连接相交；不按递质预测 `top_nt` 猜测角色。

本地注释中许多 KC 的 `top_nt` 预测为 dopamine，而文献来源的 `known_nt` 含 acetylcholine。这些字段不能混为一谈：本模块保留原符号，教学门控也不使用“多巴胺来源增益”旋钮替代。默认两条 MBON ID 是 `720575940624117245`、`720575940643309197`。连接表中它们与 KC 的注释左右侧关系交叉，按原 ID 和索引保留，不能人为交换或仅保留同侧。

目前糖/果香强度经过感觉开关门控后，被映射到固定稀疏 KC 模式；没有恢复完整 ORN→PN 嗅觉通路。教学强度是外部标量，没有重建 DAN 放电、释放、受体、分区调制或奖励预测误差。类型名称和左右侧不能单独推断趋近/回避效价。

MBON 仍通过原连接组参与网络传播；没有额外增加“MBON 放电→趋近食物”的策略解码器。因此可以研究局部权重和神经响应变化，不能保证果蝇立即表现得更聪明。实际行为仍受工程导航、P9 刺激及 CPG 控制。

设计参考：[KC→MBON 可塑性及强化模型](https://www.nature.com/articles/s41467-021-22592-4)、[更复杂的短期/长期记忆调制机制](https://www.nature.com/articles/s41586-024-07819-w)、[FlyWire 注释分类](https://www.nature.com/articles/s41586-024-07686-5)。本文算法是受启发的简化实现，没有声称复现这些论文的完整实验模型。

## 保存、导入与开发接口

- `mb_learning.jsonl`：每块真实局部活动与因子摘要，含设置/重置修订号、脑时间、实际教学信号。
- `learning_memory.json`：可选的最终完整局部边集合，存精确字符串 pre/post ID 与 factor。配置/报告也记录初始/最终控制、教学值与记忆；变更和重置作为模型时间事件保存。
- 最终配置导入只在新脑首次配置时载入相同边集合的因子，资格迹为 0；不恢复膜电位、延迟电流、随机数或身体中途状态。完整边集合、类型和范围必须匹配；缺边/多边/未知 ID 均拒绝。
- 已初始化局部模块却缺失最终记忆时，拒绝“最终配置”复现，不会假装沿用已学结果。初始条件重放与最终配置是两种不同用途，也不保证跨硬件逐放电相同。
- `mb_learning.py` 为纯参数/角色/记忆校验；`mb_learning_catalog.py` 为只读连接表预检；`mb_learning_runtime.py` 管理资格迹/因子/组合权重；`brain_worker.py` 执行实际积分与无积分控制 RPC。`habitat.py` 负责感觉桥、命令和记录。
- `GET /api/mb-learning/schema`、`POST /api/mb-learning/preview`；命令为 `mb_learning_settings`、`mb_learning_reward`、`mb_learning_reset`。没有任意文件路径或 pickle 导入。

小规模 CPU 核对、真实数据只读统计及其范围见[学习验证记录](蘑菇体学习验证记录.json)。未运行本次全连接组 CUDA、身体、浏览器或长时间集成验收；旧 Release 和交付包不自动更新。

## 学习过程观察

现在可从顶部“学习观察器”打开同步时序、增益分布与前后实际窗口比较。它读取同一脑块的实际计数和学习状态，不改变教学与模型，也不把更新后的因子误称为本块响应所用权重。历史/导入记录可只读查看，操作见[学习观察器说明](蘑菇体学习观察器说明.md)。
