# Windows 运行包许可与来源

日期：2026-10-16；版本 0.1.0-alpha.1。此页是对先前源码核对的二进制范围补充；不改变任何第三方原许可。源码与数据的 GPL/非商业边界继续见根目录中文许可及署名文档。

## 实际范围

运行包保留本项目与上游实际源码、FlyGym 默认资产、连接表、派生注释/形态、完整许可与引用；不含个人实验、生成权重或原注释 README/字段文档。原始注释 TSV/骨架下载缓存不收录，普通运行使用已准备的资源，需要重建时按外部资源清单获取。

CPython 3.13.15（python-build-standalone 20260807）及 3.12.14（20260901）复制基础解释器和标准库，不复制用户 site-packages、旧环境和全局配置。保留各自 LICENSE.txt、Tcl/Tk 原声明，并补入固定构建版本的 `licenses/CPython附属许可-*.rst`。这些附属汇总跨平台列举多个上游，不表示 Windows 包包含汇总中每一个组件；本包未修改解释器源码。构建配置和各依赖来源见 [20260807](https://github.com/astral-sh/python-build-standalone/tree/20260807) 与 [20260901](https://github.com/astral-sh/python-build-standalone/tree/20260901)。

便携 uv 0.12.18 保留 MIT / Apache-2.0 官方全文和固定来源。普通依赖使用原 wheel 字节，包括本地从随包源码构建的 FlyGym wheel；原 wheel 内的许可/NOTICE 不改写，并额外提取到 `licenses/wheels/` 方便离线阅读。实际文件和元数据见 `licenses/wheel-components.json`，精确原件 SHA256、许可文件哈希和查验依据见 [运行包二进制来源](运行包二进制来源.json)。Loguru wheel 未带独立 LICENSE，补入其 0.7.3 上游 MIT 原文。

## 原生依赖的边界

不能把 wheel 顶层许可当作内部所有二进制的统一许可。NumPy/SciPy 附带 OpenBLAS 及 GCC 运行库声明与 GCC Runtime Library Exception；原文一同保留。Pillow 的 FreeType 采用其 FTL 路径，保留 FreeType Project 与其他图像库声明；不把文档提及的 XZ 命令行脚本推定为本包实际程序。PyOpenGL 的 GLE 采用其原 COPYING 允许的 IBM source 许可路径，并保留 COPYING.src 与原声明，不强行改成 GPL-only。

MuJoCo 3.9.0 wheel 自带第三方许可明确采用 `EIGEN_MPL2_ONLY`，保留其 MPL 及其他原声明。[MuJoCo 源码和构建配置](https://github.com/google-deepmind/mujoco/tree/3.9.0)及[固定依赖文件](https://github.com/google-deepmind/mujoco/blob/3.9.0/cmake/MujocoDependencies.cmake)给出 Eigen 提交 `ea13a98decd497a8c5588fb5de71b57bcf10d864`；对应[Eigen 源码](https://gitlab.com/libeigen/eigen/-/tree/ea13a98decd497a8c5588fb5de71b57bcf10d864)可供获取/修改，未由本项目修改。此次环境访问 GitLab 返回 403，记录的是 MuJoCo 固定构建配置的来源依据，并未谎称已下载 Eigen 存档。certifi 保留其 MPL/MIT 及随 wheel 提供的 Python、证书源文件声明。

FFmpeg 的录像 wheel **不在本运行 ZIP 内**。对缓存字节的静态检查发现其内含 `ffmpeg-win-x86_64-v7.1.exe` 和 `--enable-gpl` 构建标志，单独的 Python BSD 声明不足以替这个二进制授予再分发权。接收方按 [下载说明](下载说明.md)从原发行方下载完整 wheel；本项目不提供伪造源码承诺。PyTorch/CUDA 大 wheel 同样由接收方从官方获得，不在 ZIP 内。
