# 交付包需要另外下载的文件

> 本文针对 0.1.0-alpha.1 Windows 运行包。GitHub 源码还需连接表、两套已有 Python 和便携 uv，位置及链接见 [源码安装说明](源码安装说明.md)。

## 必需：PyTorch GPU wheel

运行包需额外补齐本节 PyTorch，以及下一节 imageio-ffmpeg 两个 wheel。其余普通依赖、两个 Python 运行时、连接表及默认身体/网页资源已包含。仅身体模式免 PyTorch，但仍需 imageio-ffmpeg。

- 文件名：`torch-2.11.0+cu128-cp312-cp312-win_amd64.whl`
- [官方直接下载](https://download-r2.pytorch.org/whl/cu128/torch-2.11.0%2Bcu128-cp312-cp312-win_amd64.whl)
- [官方 CUDA 12.8 wheel 索引](https://download.pytorch.org/whl/cu128/torch/)
- 精确大小：`2753189216` 字节，约 2.56 GiB。
- SHA256：`7c78215c3af4f62e63f2b2e360f1722fc719b0853c7ac22666483d9810613a4c`
- 保存位置：**解压目录\downloads\上述完整文件名**。

文件名中的 `cp312` 对应包内脑模型的 Python 3.12；`win_amd64` 对应 Windows x64，`cu128` 对应 CUDA 12.8 运行时。不要下载 CPU、Linux、Python 3.13 或其他 CUDA 版本来替代这个文件。

发送方电脑已有此文件时，可直接另行发送，省去重新下载。安装脚本会先验证大小和 SHA256，再离线安装。

PowerShell 手动核对：

```powershell
Get-FileHash '.\downloads\torch-2.11.0+cu128-cp312-cp312-win_amd64.whl' -Algorithm SHA256
```

## 必需：录像 wheel（含 FFmpeg）

- 文件名：`imageio_ffmpeg-0.6.0-py3-none-win_amd64.whl`
- [原发行方 PyPI 文件](https://files.pythonhosted.org/packages/2c/c6/fa760e12a2483469e2bf5058c5faff664acf66cadb4df2ad6205b016a73d/imageio_ffmpeg-0.6.0-py3-none-win_amd64.whl)
- [版本页面](https://pypi.org/project/imageio-ffmpeg/0.6.0/)
- 大小：`31246824` 字节，约 29.8 MiB。
- SHA256：`02fa47c83703c37df6bfe4896aab339013f62bf02c5ebf2dce6da56af04ffc0a`
- 保存到 `downloads`，保留完整文件名。Setup 会先校验再安装；缺少或错误会报错，不会偷偷下载。

此 wheel 内含独立 FFmpeg 可执行文件。我们没有将 Python 包的 BSD 声明扩大到该可执行文件，也不在运行 ZIP 内再分发它；由接收方从原发行源获取。完整及仅身体安装均需补齐，安装后可用 `--no-video` 关闭录像。

## 条件需要：Windows / 显卡系统组件

这些不是项目自动安装的内容；现有电脑若能正常运行则不需要额外操作。

- 需要更新 NVIDIA 驱动时，从 [NVIDIA 官方驱动页面](https://www.nvidia.com/Download/index.aspx)选择适合自己显卡的驱动。CUDA 能否使用，以本包 GPU 自检为准。
- 出现 `VCRUNTIME`、`MSVCP` 或 DLL 缺失错误时，参考 [Microsoft 官方 Visual C++ Redistributable 页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)，选择 x64；[官方 x64 安装器](https://aka.ms/vc14/vc_redist.x64.exe)。系统运行库需要用户自行按微软说明安装，本项目脚本不会代装。

不需要单独安装 CUDA Toolkit、Visual Studio 或 WSL。

## 二次开发可选

[Node.js 官方下载](https://nodejs.org/en/download)。只在运行 `verify_activity_groups.mjs` 等前端统计检查时需要，已验证版本为 Node.js 24；普通游玩无需 Node.js。
