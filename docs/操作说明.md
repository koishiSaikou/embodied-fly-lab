# 操作说明

目标版本 0.1.0-alpha.1，第三方 Windows 本地 Demo。新源码安装见 [源码安装说明](源码安装说明.md)；已有本机项目继续使用现有环境。本版本 Windows 运行包先看 [交付包说明](交付包说明.md)，补齐两个外部 wheel 后用包内 Setup.cmd 离线安装；历史交付包说明仅供查旧，不是本版本入口。

## 启动与退出

双击 Start-Habitat.cmd，在控制台打印的实际网页地址操作。默认持续运行；加载中等待脑初始化。Ctrl+C 会先保存再退出，保持控制台打开到收尾完成。启动参数、其他模式、端口与日志位置详见 [启动与停止](启动与停止说明.md)。

## 工作台

顶部打开地图、栅格、大类曲线、类型曲线、身份查询和活动总览。窗口可拖动、缩放、折叠与收起。右侧按类别展开调整项并应用；重置布局只影响窗口位置，不重置脑、身体或实验。

“暂停”保留当前状态并停止模型时间。“结束并保存”结束本轮；等保存后点“开始新一轮”，按初始配置初始化新脑与身体，创建新目录。关闭浏览器不会停止后台。

## 调整与观察

- 脑模型：P9 通道刺激、共同刺激、糖输入、反馈开关/增益及运动读出平滑。以服务器确认的值为准。
- 递质：按预测 top_nt 调整来源突触作用增益，保留符号、原始缓存与未知组 1 倍；不是直接调真实递质浓度，也不是突触学习。
- 环境：编辑食物、果实、气味、光、水、危险等元素和感觉开关；造型用于辨识，代理场不等于流体/热物理。
- 行为：探索、觅食、环境反应、需要与外置气味偏好；奖励/记忆是工程层。清洁程序用真实关节驱动，不是复原的清洁神经回路。
- 脑活动：按实际事件显示分类与放电；缓冲不完整时计数是采集到的下限。显示设置不改变脑模型。

## 记录与错误

每轮在 output/habitat/新目录记录配置、轨迹、神经、感觉、行为、图像/视频及报告；新报告 project 字段保存应用/数据版本和报告格式版本。既有历史记录不改写。录像可以通过 --no-video 关闭。

错误后先收尾并保留已有数据；只有明确点击才新开。参见 [异常处理与恢复](异常处理与恢复说明.md)。长时资源保护暂缓，详见 [已知限制](已知限制.md)。

## 指定目录保存与导入运行

指定目录：主页面保存按钮旁新增“另存到…”，可浏览或手输现有绝对目录；结束并收尾后由后端另存唯一 ZIP，保留默认记录，不覆盖已有文件。顶部“导入实验”进入 ZIP 导入；“导入后运行…”会先导入并选中记录，再由用户确认初始重放或最终配置新实验。

## 查看、分享与复现已有实验

底部“实验记录 · 导入与分享”打开记录页。结束并保存后可导出包含数据、配置、来源和 SHA256 清单的 ZIP；导入会创建独立新记录，不覆盖本地旧实验。运行中可以查看已写出的部分数据，但不能导出或强行新开另一轮。

只看记录时双击 `View-Records.cmd`，按控制台显示的 URL 打开；不加载脑或身体。网页可看轨迹、神经块汇总、行为、配置、图像与录像，预览有明确抽样限制。

在主实验场收尾完成后，可选择初始条件及模型时间设置事件重放，或用最终配置与外置气味价值开始新实验。两者都会重新初始化脑与身体。具体操作见[实验保存与分享说明](实验保存与分享说明.md)。已发布的旧版本 ZIP 不会自动增加这些本机源码功能。

## 虚拟神经干预

重新启动新版实验场，在右侧“神经干预”分类检查精确ID或类型目标，设定模型时间窗后应用刺激或静默；到期结束，也可手动取消。暂停修改不推进模型时间；计划窗口与真实作用时间分别显示。操作、实验解释与保存重放边界见[虚拟神经干预说明](虚拟神经干预说明.md)。

## 蘑菇体局部学习

重新启动新版实验场，进入右侧“局部学习”，检查默认目标后开启模块并应用。手动教学0.5/1为持续门控，需点0停止；也可切到糖接触代理。关闭可塑性以冻结因子，关闭总开关则临时绕过已学因子。保存/导入可沿用局部记忆，具体步骤与限制见[蘑菇体局部学习说明](蘑菇体局部学习说明.md)。

## 学习观察器

顶部“学习观察器”或局部学习分类入口可打开可拖动浮窗，显示统一模型时间的六条轨道、块后突触因子分布与前后窗比较。先启用局部模块，稳定运行足够模型时间后捕获窗口；暂停改设置后须等待新的完整窗口。结束保存后，可在历史记录的“蘑菇体学习”中打开只读图表，朋友导入ZIP也能查看。见[蘑菇体学习观察器说明](蘑菇体学习观察器说明.md)。
