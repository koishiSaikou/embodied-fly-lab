# v0.1.0-alpha.2 · 保存分享、神经干预与局部学习

本版把具身果蝇实验场扩展为可以保存交换实验、干预选定神经元、观察局部突触学习的本地Demo。提供对应源码与Windows x64运行包，标记为Pre-release；保留alpha.1历史版本。

## 新增功能

| 功能 | 内容 |
| --- | --- |
| 保存与分享 | 初始/最终配置、实际数据、模型时间设置事件；指定目录另存ZIP，历史与独立查看器，校验导入导出 |
| 条件重建 | 初始条件与事件重放，或最终设置/外置记忆/局部因子启动新轮；不覆盖来源实验 |
| 虚拟神经干预 | 精确ID/类型选择，定时附加刺激、静默、取消，记录实际执行时间和目标放电 |
| 蘑菇体局部LTD | 默认关闭；默认KCg-m→MBON01的1865条既有正边，支持外部教学、冻结、重置、因子保存导入 |
| 学习观察器 | 气味、KC活动、教学、资格迹、突触因子和MBON响应的同步时间线，实际窗口前后比较与增益分布 |
| 历史图表 | 保存或导入后复用同一观察器只读查看，无需加载脑或身体仿真 |

## 下载与安装

- **普通体验**：下载本页 `FlyWire-Windows-0.1.0-alpha.2.zip` 和可选 `.zip.sha256`。完整解压到新的英文/ASCII路径，阅读包内“开始使用.md”，补齐两个外部wheel，再运行Setup.cmd、Start-Habitat.cmd。
- **源码开发**：使用本页Source code或Git检出该标签，按[源码安装说明](https://github.com/koishiSaikou/embodied-fly-lab/blob/v0.1.0-alpha.2/docs/源码安装说明.md)准备环境。
- 运行包带两套项目专用便携Python、普通依赖、连接表与资源；不覆盖系统Python、不修改全局PATH、不需要WSL。全脑模式需兼容固定CUDA wheel的NVIDIA GPU/驱动，建议预留20GB磁盘。
- **外部文件仍需自行下载**：PyTorch CUDA wheel（约2.75GB）和imageio-ffmpeg wheel（约31MB），按原名放入downloads；准确链接、大小与SHA256见[下载说明](https://github.com/koishiSaikou/embodied-fly-lab/blob/v0.1.0-alpha.2/docs/下载说明.md)。既有正确同名文件可复用。

新版请解压到新目录，保留旧包/环境/实验，不覆盖正在运行的项目。alpha.1与旧开发阶段记录可继续查看；跨版本重建可能因版本或关键源码SHA不同而拒绝。复现是新开实验，不恢复膜电位、资格迹、随机数和身体完整中途状态，不保证跨GPU逐放电完全相同。

## 操作入口

- 右侧“神经干预”：检查目标并设定模型时间窗。
- 右侧“局部学习”：检查目标、开启模块、选教学来源。手动教学0.5/1为持续门控，点击0停止；冻结保留因子用于读出。
- 顶部“学习观察器”：查看统一模型时间曲线、捕获前后完整窗口并核对条件差异。
- “结束并保存”/“另存到…”：保存本轮。`View-Records.cmd`或网页历史页可导入、查看和导出；“蘑菇体学习”分类打开历史图表。
- 完全退出在控制台按Ctrl+C，等待保存结束；关闭浏览器不会停止后端。

## 模型边界与验证范围

全脑仍是连接组上的统一简化LIF，局部学习只影响选中已有正边的临时因子，原始数据和上游方程不改。气味KC桥和教学信号是工程代理，没有完整ORN/PN/DAN通路、VNC、受体浓度机制或学习出的MBON→行为解码器；不保证果蝇训练后自动改善觅食。可比较窗口也不是学习因果证明。

保存导入阶段做过隔离短程实跑；神经干预、局部学习和观察器分别进行了9、58、89项小规模CPU/数据/纯逻辑等核对，证据仅覆盖对应阶段和记录的源码。**本次打包不新增安装、完整全脑CUDA/身体/浏览器、性能或长时验收**；逐文件哈希核对仅证明构建字节一致。长时资源保护继续暂缓。
