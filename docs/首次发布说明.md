# v0.1.0-alpha.1 · 首个公开测试 Demo

**果蝇感觉与行为实验场 · 首个公开测试 Demo**

这是第三方本地实验演示，基于 FlyGym / NeuroMechFly 身体、FlyWire FAFB v783 连接组和 Eon 的统一 LIF 实现，接入真实复眼采样、工程多感官环境与外置气味偏好记忆。它不是官方 FlyWire 产品，不代表已经完整复原真实果蝇大脑、生理或自然行为。

## 可体验内容

- 观察三维身体、复眼、场地轨迹、实际放电和按类型分组的脑活动。
- 编辑食物、气味、光、水、危险区等环境元素，并调整感官开关。
- 调整刺激、脑—身体反馈、运动平滑和预测递质来源增益。
- 体验工程探索、觅食、环境反应、右前足清洁与外置偏好学习。
- 暂停、保存、手动新开实验；脑响应超时后显示原因并尝试保存已有记录。

## 安装与范围

面向 Windows x64 与桌面横屏；全脑需要 NVIDIA GPU/驱动，路径使用英文/ASCII，可带空格。普通使用者下载本页附件 **FlyWire-Windows-0.1.0-alpha.1.zip**，完整解压后先读 `开始使用.md`。它带两套项目专用 Python、大部分依赖、连接表和身体/网页资源，不覆盖系统 Python。开发者也可使用本页 Source code 源码归档，按[源码安装说明](https://github.com/koishiSaikou/embodied-fly-lab/blob/v0.1.0-alpha.1/docs/源码安装说明.md)安装。已有本机环境不需重装。

运行包需要按[下载说明](https://github.com/koishiSaikou/embodied-fly-lab/blob/v0.1.0-alpha.1/docs/下载说明.md)另下载两个原发行文件，均放入解压目录 `downloads`：PyTorch CUDA wheel（约 2.75 GB）和 imageio-ffmpeg wheel（约 31 MB）。补齐后用 Setup.cmd 离线安装。仅身体模式也需要录像 wheel，但无需 PyTorch。源码归档则还需自行准备 Python、uv 和连接表。

附件的 `.zip.sha256` 用于核对下载完整性，运行包内另有逐文件清单和实际源码提交。源码与运行包都不包含个人实验或生成的权重缓存。旧日期 ZIP 不作为本版本附件。

## 已知边界

速度可能低于实时；统一 LIF 不是完整生理模型，没有完整 VNC 或全脑突触可塑性。感觉、需要和行为包含工程规则/代理场，学习在外置记忆层。三维形态仅 16 个骨架与 78 个静态脑区。长时间运行的内存/磁盘保护暂缓，记录仍会增长。

这是 Demo，按维护者要求，本轮许可、版本及文档改动没有追加功能/GPU/性能/长时测试，既有验证只对应其发生时的版本。不承诺全部电脑兼容或长期稳定性。
