# v0.1.0-alpha.1 · 具身果蝇实验场首个公开测试版

把公开的果蝇脑连接组、简化神经计算、三维身体和多感官环境接成一个可交互的本地实验场。你可以观察实际放电与身体运动、编辑环境、调整刺激和反馈，并体验工程行为与外置气味偏好学习。

**版本类型：Pre-release / Alpha Demo。** 面向 Windows x64、桌面横屏；这是第三方实验项目，不是 FlyWire 官方产品，也不代表已经完整复原真实果蝇。

## 本版概述

| 内容 | 你能做什么 |
| --- | --- |
| 身体与复眼 | 观察 NeuroMechFly 身体、行走、转向、接触、右前足清洁与实际左右复眼采样 |
| 脑活动 | 查看放电栅格、群体与类型曲线、身份查询及部分骨架和静态脑区 |
| 刺激与反馈 | 调整输入强度、运动反馈、平滑和预测递质来源突触增益 |
| 场地与行为 | 编辑食物、果实、气味、水、光和危险区；体验探索、觅食、环境反应和外置学习 |
| 工作台与记录 | 折叠、移动图表；暂停、结束保存和手动开始新一轮 |

模型使用 FlyWire FAFB v783 的 138,639 个节点和 15,091,983 条带权神经元对记录，以统一 LIF 近似放电。P9 是主要运动读出接口；显示的 16 个真实骨架与 78 个静态脑区仅是形态展示范围。

## 安装与运行

1. 完整解压 Windows 运行 ZIP 到纯英文/ASCII 路径，例如 `D:\FlyLab`，可带空格；不要在 ZIP 内运行。
2. 补齐上面两个 wheel，先读包内 **开始使用.md**。
3. 双击 **Setup.cmd**，等待校验、离线安装及安装器诊断结束。
4. 双击 **Start-Habitat.cmd**，等待脑初始化；网页实际地址与端口见控制台。
5. 可暂停、结束保存和手动重开；完全退出按控制台 **Ctrl+C**，等待保存与子进程退出。关闭浏览器不会停止后端。

全脑模式需要兼容固定 CUDA wheel 的 NVIDIA GPU/驱动，建议预留 20 GB 磁盘空间。随包 Python 和环境只在项目目录内使用，不覆盖系统 Python、不修改全局 PATH；无需 WSL。只看身体可用 `Setup.cmd --body-only` 后运行 `Start-Body.cmd`。

## 已知限制与反馈

- 统一 LIF 不是完整神经生理模型；没有完整腹神经索、感觉通路、递质浓度/受体动力学或全脑突触可塑性。
- 感觉和运动包含工程策略；气味价值学习在外置记忆层，不是全脑模型自主学会了这些行为。
- 模型可能慢于实时。长时内存/磁盘保护暂缓，记录会增长；其他系统与显卡组合未普遍验证。
- 本轮未新增安装、仿真、GPU、性能或长时测试。逐文件哈希核对只说明包内文件一致，不代表功能或跨电脑兼容性验收。

详情见[已知限制](https://github.com/koishiSaikou/embodied-fly-lab/blob/main/docs/已知限制.md)。欢迎在 [Issues](https://github.com/koishiSaikou/embodied-fly-lab/issues)反馈，附版本、Windows/显卡信息、启动方式、复现步骤与错误片段，先移除个人路径和敏感信息。
