# 快速开始

适用目标：0.1.0-alpha.2，Windows x64 桌面横屏 Demo。新下载源码先按 [源码安装说明](源码安装说明.md)准备环境；你已有的本机项目直接使用现有两个环境，不需要重新安装 Python。

1. 将项目放在英文/ASCII 路径，路径可以带空格。全脑模式需要 NVIDIA GPU 与可用驱动。
2. 源码目录按安装说明准备 Python 3.13 / 3.12、uv、连接表和指定 CUDA wheel，再运行 Setup.cmd。已有环境不必重复安装。不要使用 requirements-*-installed.txt 的历史本机路径快照安装。
3. 双击 Start-Habitat.cmd，保持控制台打开。浏览器在服务就绪后打开，实际端口见控制台。
4. 等待脑加载完成后观察；顶部开关观测窗口，拖标题移动，右下角调整尺寸；右侧按类别调整后应用。
5. 暂时停住用“暂停”；结束本轮用“结束并保存”，等保存完成后可“开始新一轮”。记录在 output/habitat/本轮目录。
6. 完全退出在该控制台按 Ctrl+C，等待保存与进程关闭。关闭浏览器不会停掉后端。

更多操作见 [操作说明](操作说明.md)、[启动与停止](启动与停止说明.md)。脑超时和错误记录见 [异常处理](异常处理与恢复说明.md)。模型简化、长时记录增长和旧包限制见 [已知限制](已知限制.md)。
