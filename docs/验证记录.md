实际使用了随包的 Python 3.13.15（身体/网页）及 Python 3.12.14（脑），不是调用电脑原有 Python。PyTorch 为 2.11.0+cu128，CUDA runtime 为 12.8。完整短测约用时 43 秒；这只是本机一次验证耗时，不是实时仿真的速度保证。

已发现并处理的限制：中文目录下 MuJoCo 不能读取部分身体网格。安装器会在安装前明确拒绝非 ASCII 路径；请使用 `D:\FlyWire` 等纯英文路径。英文路径允许空格。

接收方可先运行 `Check-Environment.cmd` 检查，再运行 `Smoke-Test.cmd` 复测身体、GPU 脑和闭环网页接口。日志及 JSON 结果分别保存在 `output/setup` 和 `output/self_test`。首次脑测试会从随包连接表生成权重缓存；生成的 pickle 字节不保证与开发机完全相同，验证按实际连接索引和数值判断。

验证范围是这台已知 Windows / NVIDIA 测试机。朋友电脑的不同 GPU、驱动和系统组件仍需运行 `Check-Environment.cmd`，不声称已经在所有 Windows 电脑验证。
