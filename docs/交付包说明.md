# FlyWire Windows 本地实验场

> 本文描述原离线交付包；GitHub 源码安装见 [源码安装说明](源码安装说明.md)。本次没有更新原交付包。

这是“真实果蝇连接组 + 简化 LIF 脑模型 + 三维物理身体 + 工程感觉/行为闭环”的 Windows x64 源码交付包。

**不会覆盖你电脑已有的 Python。** 附带的 Python 3.13/3.12、安装后的两个虚拟环境、依赖和缓存都在本目录；安装脚本不修改系统 PATH、注册表或全局 Python 包。不需要 WSL。

## 朋友拿到后先做这四步

1. 完整解压到有足够空间的**纯英文路径**，例如 `D:\FlyWire`（可带空格），不要在压缩包预览里运行。MuJoCo 在 Windows 下读取中文路径中的网格会失败。
2. 按 [下载说明](下载说明.md)，下载唯一需要另外补齐的大文件 PyTorch CUDA wheel，放进本目录的 `downloads` 文件夹。也可以让发送方直接把他已下载的同名文件发给你。
3. 双击 `Setup.cmd`，等待校验和离线安装完成。
4. 双击 `Start-Habitat.cmd`，等待浏览器自动打开实验场。默认先尝试 8472 端口；占用时自动换用其他空闲端口，以控制台地址为准。

实验场默认持续运行，直到手动结束；不会在 30 秒自动停止。网页点“结束本次实验并保存”后，可直接点“按初始配置开始新一轮”，不用关闭启动窗口。

只想先看身体：运行 `Setup.cmd --body-only`，再双击 `Start-Body.cmd`，此时不需要 PyTorch wheel。

**连接表完整载入，不等于已复原完整生物果蝇。** 原交付包版本没有学习或类型特异生理（本机后续外置气味学习尚未重新打包），腹神经索以步态控制器近似。模型时间通常慢于现实时间。
