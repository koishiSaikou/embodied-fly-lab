# Windows 运行包：开始使用

版本：**0.1.0-alpha.2 · Pre-release**。这是按当前源码更新的 Windows x64 运行包，不是旧日期命名的 ZIP。包含连接表、注释、脑模型源码、身体和网页资源、两套隔离 Python、普通依赖及许可原文；不含个人实验、已有虚拟环境和权重缓存。

## 安装

1. 完整解压 Release 附件 `FlyWire-Windows-0.1.0-alpha.2.zip` 到纯英文/ASCII 路径，例如 `D:\FlyLab`，可带空格。不要在 ZIP 里运行。
2. 按 [下载说明](下载说明.md)下载 PyTorch 与 imageio-ffmpeg 两个 wheel，原名放入 `downloads`。仅身体模式也需录像 wheel，免 PyTorch。
3. 双击 Setup.cmd，等待逐文件及外部文件校验、离线安装和安装器自带诊断结束。无需管理员权限，不联网下载，不替你安装显卡驱动。
4. 双击 Start-Habitat.cmd。等待脑加载，使用控制台打印的实际网页地址；默认从 8472 寻找空闲端口。

**不会覆盖已有系统 Python。** 随包解释器、安装后的 `.venv` / `.brain-venv`、依赖、缓存和记录均在本项目目录；不修改全局 PATH、注册表或全局 Python 包，不需要 WSL。系统驱动/DLL 缺失时按下载说明从官方补齐。

只看身体：补齐录像 wheel 后，在终端运行 `Setup.cmd --body-only`，再双击 Start-Body.cmd。建议至少预留 20 GB 磁盘空间；全脑需兼容固定 CUDA wheel 的 NVIDIA 显卡和驱动。本机硬件不是经过测试的最低配置。

## 操作与停止

默认持续运行，不会到 30 秒自动结束。网页可暂停、结束并保存、手动开始新一轮；完全退出在对应控制台按 Ctrl+C，等待保存和子进程关闭。关闭浏览器不会停止服务。

新版包含桌面工作台、分类脑活动、多感官场地、递质来源增益和工程行为；新增实验保存分享、指定目录另存、虚拟神经干预、蘑菇体局部LTD与同步学习观察器。View-Records.cmd可单独查看保存/导入后的记录与学习图表。详见 [操作说明](操作说明.md)、[启动与停止](启动与停止说明.md)、[项目详情](项目详情.md)。AI 修改前先读根目录 [AI协作约定](../AI协作约定.md) 和 [AI二次开发文档](AI二次开发文档.md)。

请在新目录安装新版，保留旧包和旧实验；不要覆盖正在运行的旧目录。新版本不自动迁移或改写旧实验。`bundle-manifest.json` 保存实际源码提交与逐文件 SHA256，ZIP 附件另有总 SHA256。
