# Windows 操作说明

> 从 GitHub 下载的源码先看 [源码安装说明](源码安装说明.md)。下文涉及随包解释器、wheels 和离线 Setup 的部分针对旧交付 ZIP；本源码的 Setup 在项目内创建新环境并复用已有基础 Python。

> 当前源码的五个启动器已经统一；自动打开网页、自动换端口、日志和 Ctrl+C 保存退出见 [启动与停止说明](启动与停止说明.md)。原交付 ZIP 不随源码自动更新。

## 1. 环境与安全隔离

本包用于 Intel/AMD 的 **Windows x64**，全脑模式需要能运行本包 PyTorch CUDA 的 NVIDIA 显卡。Windows ARM 和没有 NVIDIA CUDA 的电脑不在本包全脑验证范围。

| 用途 | Python 要求 | 随包版本 | 位置 |
| --- | --- | --- | --- |
| 身体、网页、视觉、数据处理 | Python 3.13 x64 | 3.13.15 | `_runtime\python313` → `.venv` |
| 脑模型 | Python 3.12 x64 | 3.12.14 | `_runtime\python312` → `.brain-venv` |

两套环境因固定 wheel 的 Python ABI 分开使用。即使已有系统 Python，默认脚本也只调用随包解释器，不会覆盖或卸载现有版本，不修改全局 PATH、注册表或全局包。所有项目依赖、临时文件、缓存和输出均使用解压目录。

原测试机为 R9 9955HX、32 GB 内存、RTX 5070 Ti Laptop 12 GB；没有系统测试所有最低配置，不把这组配置当作硬性最低要求。建议保留至少 **20 GB 空闲磁盘空间**，包含额外 wheel、安装展开文件、权重缓存及后续记录。

## 2. 首次安装

1. 完整解压到**纯英文/ASCII 路径**，例如 `D:\FlyWire` 或 `E:\Games\FlyWire`，可含空格。Windows 下 MuJoCo 无法可靠读取中文路径内的网格，安装脚本会提前检查。不要放在含中文用户名的桌面/下载目录，不要解压到只读目录，也不要在 ZIP 内直接运行。
2. 根据 [下载说明.md](下载说明.md) 下载固定的 PyTorch wheel，放到 `downloads`，保留完整文件名。
3. 双击 `Setup.cmd`。不需要管理员身份，安装过程不联网。它会核对包内清单、外部 wheel 的大小和 SHA256，创建两个本地虚拟环境，并检查依赖与 GPU。
4. 出现 `Installation complete` 后，双击 `Start-Habitat.cmd`。

需要先确认整条链路时，可双击 `Smoke-Test.cmd`：它会实际运行短身体录像、GPU 脑刺激、0.2 秒完整闭环及本机网页接口检查，并把结果保存在 `output\self_test`。

仅身体模式可在终端运行：

```powershell
.\Setup.cmd --body-only
.\Start-Body.cmd
```

只校验原始交付包，不安装环境：`Setup.cmd --check-package`。

安装后移动整个目录时，先关闭本项目的控制台/仿真，再在新位置重新运行 `Setup.cmd`。脚本会更新本地虚拟环境的解释器路径并复核依赖，不需要重装系统 Python。保留新目录的 `downloads` 中 PyTorch 文件，重跑安装仍会校验它。

## 3. 推荐：网页实验场

双击 `Start-Habitat.cmd`。默认从 8472 开始寻找可用端口，并自动打开浏览器。若没有自动打开，请复制控制台的 `http://127.0.0.1:端口/`。

启动时会载入全脑数据、编译部分数值函数，第一次还要生成约 0.6 GB 的稀疏权重缓存。窗口没有立刻运动时先观察控制台，不要连续双击启动多个实例。

- **暂停 / 继续**：暂停整个模型时间。
- **跟随 / 全景**：改变观察相机；拖动旋转、滚轮缩放、右键平移。
- **移动食物**：开启后在俯视地图空白位置点击；越界或与障碍重叠的位置会拒绝。
- **视觉 / 气味 / 避障 / 糖味**：切换输入或工程反馈，便于观察对照。
- **结束本次实验并保存**：停止当前一轮并保存记录，网页服务继续保留。
- **按初始配置开始新一轮**：新建记录，重新初始化脑和身体；恢复启动时配置。
- **关闭浏览器不会关闭服务**。结束使用时，在对应控制台按 `Ctrl+C`，等它完成保存再关闭。

默认**持续运行，直到手动结束**，不会再到 30 秒模型时间自动停止。点“暂停”可以原地暂停/继续；点“结束本次实验并保存”会保存当前一轮，随后点“按初始配置开始新一轮”即可重开，无需关闭 CMD。新一轮会重新初始化脑和身体，原记录保留。脑活动页的“暂停图表”仅冻结图表，和实验场的整体暂停不同。

需要定时实验时用 `--seconds 60` 指定 60 秒模型时间，`--seconds 0` 表示持续运行。模型时间与现实时间不同。调整时长、端口或关闭录像，可在项目目录终端运行：

```powershell
.\_runtime\python313\python.exe delivery\launch.py habitat --seconds 60 --port 8480 --no-video
```

## 本机桌面工作台

本机主页现采用 Blender / C4D 风格的单屏工作台：左侧复眼和脑图、中央三维、右侧分类属性。顶部按钮按需打开可拖动、折叠和缩放的地图及图表，底部显示记录目录；参数和长表只在各自面板内滚动。脑参数分组展开后修改并应用，地图编辑在右侧“场景”中操作。详细操作见 [工作台布局说明](工作台布局说明.md)。刷新主页即可使用，不必重启当前实验；现有交付包仍保持原版本。

## 4. 看脑活动

主页顶部“活动总览”用于筛选与分类统计；“放电栅格 / 大类曲线 / 类型曲线”分别打开对应图表。也可点左下角“独立脑活动页”。

- 可按 10 个大类、8,845 种具体类型筛选，未知类型单列。
- 栅格每个点对应采集到的一次放电；大类用不同颜色。
- 平均 Hz 的分母包含该类本窗没放电的神经元。总放电率和平均率可切换。
- 图表只显示最近最多 1 秒模型时间，实验结束后显示最后保存窗口。
- 栅格最多 300 个活动行；统计仍包括缓冲区内所有事件。事件缓冲不完整时会给出下限提示。
- 点击统计行/类型行聚焦，点击活跃神经元查看身份。主页筛选会联动已有骨架。
- 三维脑图只有已下载的 16 个真实骨架和 78 个静态脑区模板，分类统计覆盖全部模型节点。
- P9 即 DNp09，是当前连接身体的主要接口，指标保留在折叠区。其余神经元并非“没有运行”。

具体类型、递质预测和文献来源可在“神经元身份与类型”中查询。已知类型覆盖率为 98.92%；1,492 个类型未知，其中 14 个 ID 没有对应注释行。

| `Start-Habitat.cmd` | 推荐：完整脑、身体、感觉环境和网页 |

## 脑刺激与反馈调整

实验场右侧“脑模型”中提供“刺激输入 / 运动反馈 / 递质来源突触增益”折叠组。可以把这些选项理解为“输入脑的信号音量”和“脑输出到身体的音量”。修改后点击“应用到本轮实验”，等待“配置已应用”；也可以一键恢复默认。暂停时允许修改，继续后使用新配置计算，不需要重开脑模型。

| 调整项 | 默认 / 范围 | 作用 |
| --- | --- | --- |
| P9 通道 A / B 刺激增益 | 各 1 倍 / 0–3 倍 | 分别缩放工程策略给两通道的刺激；通道顺序保持原样 |
| P9 共同基础刺激 | 0 / 0–100 Hz | 增益计算后，两通道各加同一频率；增益为 0 时仍有这项基础刺激 |
| 糖味神经元刺激增益 | 1 倍 / 0–3 倍 | 缩放实际食物接触触发的糖 GRN 输入；没有接触就没有额外糖刺激 |
| 脑到身体反馈增益 | 1 倍 / 0–1.5 倍 | 缩放脑读出的步态幅度，最终幅度上限仍为 1.2；不是直接设定走路速度 |
| 运动反馈平滑时间 | 100 / 20–500 模型毫秒 | 大值让运动输出变化更缓，小值更快跟随 P9 放电读出 |
| 启用脑到身体运动反馈 | 开 | 关闭时身体驱动为零，脑仍继续计算；物理碰撞、重力等仍可能使身体移动 |

两边刺激增益同时为 0、基础刺激为 0，才会关闭 P9 外部刺激。糖味刺激增益为 0 不会取消工程策略本身的食物停留规则。身体停留、后退和转向方向仍受策略控制，所以增加刺激不保证果蝇会立即前进。上表的基础项不修改连接权重；下面的递质项会改变本轮有效权重，两者均不修改 LIF 方程或引入学习。

### 按递质来源调节突触作用

展开“递质来源突触增益 · 简化干预”，可分别调节乙酰胆碱、谷氨酸、GABA、多巴胺、血清素（5-HT）和章鱼胺，范围均为 **0–2 倍，默认 1 倍**。

- **0 倍**：该预测递质组神经元的后续循环突触输出为零；外部 P9/糖刺激仍可让这些神经元放电，已经进入延迟队列的信号仍会衰减。
- **1 倍**：使用原始连接强度。六项均为 1 时，直接使用原始权重张量。
- **2 倍**：该组神经元发出的连接权重幅度变为两倍，保持原有正负号；不会把负权重变为正权重。

分组依据是突触前（发出信号）神经元的 `top_nt` 预测，不是接收信号一侧的递质。面板显示每组人数、原始输出连接数量及其中原正/原负连接数，没有按预测置信度筛掉神经元。当前预测未知或未匹配的 293 个神经元、394 条输出连接固定 1 倍。

修改后点“应用到本轮实验”，不重置当前脑状态；暂停时的配置在继续后的计算块才进入 GPU。“最近计算块递质增益”显示最后实际用于计算的值。恢复默认仅恢复连接强度，不倒退已经演化的神经状态；严格比较时应从相同种子的新一轮分别实验。

这是按预测组缩放连接的简化实验，不是递质浓度、受体种类、释放/回收、扩散或真实奖励信号的仿真。多巴胺增益不代表奖励学习，也不保证某种固定行为。这里不会改写原始连接组、注释表或权重缓存。基础记录包含所有递质旋钮；`neural.jsonl` 还记录每个已计算块的 `transmitter_gains`，最终 `report.json` 的 `brain_effective_transmitter_gains` 区分最后实际计算值与暂停时已提交但未计算的配置。

这些参数用于本轮实验，网页刷新后会重新读取已应用配置，重开新一轮恢复默认值。初始值写入 `config.json`，每次实际应用的前后值及模型时间写入 `events.jsonl` 的 `brain_settings` 事件，结束时的配置写入 `report.json` 的 `brain_controls_final`。暂停时显示的“最近计算块输入”仍来自暂停前，继续后才会产生新读数。若启动时指定 `--disconnect-brain-output`，该强制切断设置优先于网页反馈开关。

“全脑分类活动”和独立脑活动页还可调整：

- **模型时间窗**：最近 0.1、0.2、0.5 或 1 秒，按完整脑计算块对齐，界面显示实际起止时间。
- **栅格最多行数**：50、100 或 300 行；只缩减栅格绘制，不缩减统计的神经元范围。
- **图表刷新间隔**：0.25、0.5、1 或 2 秒现实时间；不会加快或减慢脑积分步长。

显示偏好保存在当前浏览器，主页面和同一地址的独立脑活动页共享。若缓冲事件不全，仍会明确显示统计下限提示。运行中的旧版服务需要退出后启动一次新版，再刷新网页；以后修改这些参数不需要重启。

## 6. 记录在哪里

每轮网页实验保存在 `output\habitat\时间戳\`：

- `config.json`：初始环境、参数和模型假设。
- `trajectory.csv`：位置、感觉输入、指令、放电和运动记录。
- `neural.jsonl`：每块脑活动；`events.jsonl`：交互操作。
- `retina.jsonl`：实际复眼输入。
- `report.json`、`monitor_snapshot.json`：结果和最后状态。
- 开启录像时有 `arena.mp4`、`arena.png`，另有轨迹与访问分布图。
- `brain_worker.log`：脑进程日志。

安装诊断在 `output\setup\`。向发送方或 AI 反馈故障时，优先提供具体错误、`diagnostics-*.json` 和对应运行的 `brain_worker.log`。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到 PyTorch wheel | 按下载说明放到 `downloads`，不要把 `.whl` 改成 `.zip` 或另存为网页 |
| SHA256 不匹配 | 核对精确文件名、大小与哈希，重新下载；不要跳过校验 |
| `CUDA is unavailable` | 检查是否有兼容 NVIDIA 显卡、驱动是否正常；运行环境检查，不要安装 CPU torch 替代 |
| DLL / MSVCP / VCRUNTIME 错误 | 参考下载文档的微软 x64 运行库链接；项目不会自动安装系统组件 |
| 网页打不开 | 使用控制台实际端口，确认服务还开着；浏览器可用 Edge/Chrome |
| 运行慢、显存不高 | 当前稀疏 LIF、物理和网页协同有开销；低显存不是只算了两个神经元；可加 `--no-video` |
| 分组为 0 | 代表这段模型时间没有采集到该组放电，不等于该组没有载入 |
| 果蝇行为很机械 | 当前有工程感觉规则和外置气味学习，尚未复原生物神经可塑性及全部行为 |
| 移动目录后失败 | 关闭本项目进程，在新目录重跑 `Setup.cmd`；不要复制别人已安装的 `.venv` 代替安装 |
| 提示 non-ASCII path / 找不到实际存在的网格 | 改用纯英文路径，如 `D:\FlyWire`，再运行安装；Windows 下 MuJoCo 的底层网格读取不支持本包测试的中文路径 |
| 原始包完整性检查失败 | 从原 ZIP 重新解压；若已由 AI 修改源码，保留开发副本，再用干净解压副本安装 |

卸载时先关闭本项目的进程，再删除自己的解压目录即可。系统 Python 不受影响。
