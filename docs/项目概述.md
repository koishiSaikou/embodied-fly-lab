# 项目概述

Embodied Fly Lab（具身果蝇实验场）是一个 Windows 本地果蝇仿真 Demo。它把公开的脑连接数据、简化神经计算、可运动的三维身体和可编辑环境放到一起，便于观察和修改感觉、活动与动作之间的关系。

## 用通俗的话理解

可以把项目理解成四部分：一张按实验数据整理的“脑连线图”、沿这些连线传递信号的简化计算、带关节和接触的虚拟身体，以及带食物、气味、光和危险的场地。网页是观察和调整这些部分的工作台。

连线图告诉我们哪些神经元相连及连接权重，却不能单独告诉我们真实果蝇完整的生理和行为。项目使用统一 LIF 近似放电过程，并由工程策略把感觉转换成刺激，把部分脑输出转换成身体动作。看到果蝇避障或觅食时，需要同时考虑脑计算和工程策略的作用。

## 一轮实验发生什么

1. 身体和环境在 MuJoCo 中推进；左右眼取得图像，其他感官在相应位置采样代理信号或实际接触。
2. 工程感觉与行为策略结合刺激、需要和外置气味记忆，产生 P9 等神经元的输入。
3. 脑进程沿连接组上的稀疏连接推进简化 LIF，产生实际放电事件。
4. 当前主要运动接口读取两只 P9/DNp09 的放电率，通过步态控制器和工程方向映射作用于身体。
5. 新的位置和接触改变下一步的感觉；网页展示活动与轨迹，并将实验数据写入本机 output。

脑不是只运行页面显示的两个 P9。当前模型含 138,639 个节点、15,091,983 条带权神经元对记录，P9 是主要运动读出接口。脑的三维骨架只有 16 个已取得的样本；78 个脑区模板是静态背景。

## 适合怎样使用

- 体验本地连接组与物理身体的闭环演示，理解模型时间和现实时间的区别。
- 观察刺激、感觉开关、反馈和有效连接增益改变时，实际放电与身体运动如何变化。
- 编辑环境、比较工程行为策略，并阅读或扩展相应源码。
- 将项目交给 AI 辅助开发，前提是先阅读实现约定和生物学边界。

外置两类气味价值记忆是工程学习层；本项目没有因此实现全脑突触学习。它也不能直接用于推断真实果蝇的思想、情绪，或把行为演示当作已经验证的生物学机制。

本版另有默认关闭的KC→MBON局部LTD、定时神经干预、同步学习观察器和实验包分享。局部突触因子与外置气味价值是不同记忆，教学/气味桥仍为工程代理，未建立学习出的行为解码器。
