# 实验包格式与保存边界

实验包保存本轮实际记录与配置，用于本地查看和向其他安装了相同项目版本的人交换实验。它不包含完整脑/身体状态检查点，不能在中断位置接着计算。相同输入、随机种子与软件版本也不保证不同显卡逐帧、逐放电完全一致。

## 文件格式

ZIP 内采用固定的 `experiment/` 前缀，仅包含平铺文件；没有任意子目录。根清单 `experiment/manifest.json` 示例：

```json
{
  "schema_version": 1,
  "kind": "embodied-fly-experiment",
  "run_id": "原始轮次编号",
  "created_at": "ISO 8601 时间",
  "saved_at": "ISO 8601 时间",
  "status": "finished",
  "time_s": 30.0,
  "project": {},
  "dependencies": {},
  "files": [
    {"name": "config.json", "bytes": 123, "sha256": "64 位小写十六进制"}
  ],
  "total_bytes": 123,
  "reproducibility": {}
}
```

清单 `files` 不含清单自身，必须与所有其他成员一一对应。每个文件以流式 SHA256 校验。`project` 来自已有配置/报告的版本身份；`dependencies` 仅保存实际记录过的信息，旧实验缺失时不推断成完整软件环境。

白名单包括初始配置 `config.json`、结束配置 `final_config.json`、重现方案 `reproduction.json`（兼容 `profile.json`）、报告 `report.json` / `error.json`、页面快照、轨迹 CSV、感觉/神经块/行为/复眼/事件 JSONL、压缩场景、实际图像和可选录像。神经 JSONL 包括分块汇总，以及请求活动时实际返回的工作进程活动；事件可能因缓存上限被截断，并非全脑全部放电档案。脑工作日志、Python 环境、源连接大表、模型缓存和任意用户文件不打入实验包。

导出时还带上数据使用、引用文献、代码许可说明，以及 GPL 3.0、CC BY-NC 4.0、CC BY 4.0 全文附件。重新导出导入记录时保留包中已有的原始声明；不以本地新版本覆盖来源声明。没有这些声明的旧记录在导出阶段从当前项目根目录添加附件，原记录文件不改写。配置/报告中的历史参数仍可能含原电脑路径；它们作为数据保留，不能直接作为导入后的执行路径。

## 安全与原记录保护

- 已结束并生成报告的轮次才能导出；存在 `.recording` 标记时拒绝导出。
- 导出历史轮次时在 ZIP 内生成新清单，不修改旧实验目录。导出 ZIP 放在 `output/experiment_exports/`，每次使用独立名称与临时文件，完成后原子改名。
- 导入要求明确的格式和版本、平铺白名单、无重复成员、无链接/设备文件、无加密成员，且所有长度/哈希一致。仅接受常规存储或 deflate 压缩。
- 压缩包与展开记录上限各 16 GiB，文件条数上限 2000，单条清单上限 2 MiB，并限制异常压缩比。限制用于读取边界，不等于长期磁盘管理。
- 导入先写本次专属暂存目录，全部通过后移动到新的 `output/habitat/imported_时间_随机值/`；不覆盖现有实验。失败仅清理本次暂存目录。
- 原始清单另存 `.original_manifest.json`；`.imported.json` 记录原文件名、包哈希、导入时间和原轮次编号。这两个本地管理文件不向外导出。
- 导入不执行代码，不读取 pickle，不加载包中指定的绝对路径。重新运行只使用另一个配置验证层认可的有限字段。

## 程序接口

`experiment_store.py` 只依赖 Python 标准库：

| 接口 | 用途 |
| --- | --- |
| `ExperimentStore(root).list_runs()` | 列出轮次摘要、版本身份、时间、状态、导入来源标志 |
| `describe(run_id)` | 获取配置、报告、快照、重现方案、文件大小列表 |
| `file_path(run_id, name)` | 返回严格白名单内的普通记录文件 |
| `run_path(run_id)` | 返回严格校验过的当前项目轮次目录 |
| `export_run(run_id)` | 生成完整实验 ZIP，返回路径 |
| `save_to_directory(run_id, destination)` | 将实验 ZIP 校验后另存到用户明确选择的现有可写目录；保留原记录并使用唯一文件名 |
| `import_bundle(path)` | 校验并导入 ZIP，返回新轮次详情 |
| `preview(run_id, kind, limit=500)` | 有界读取实际轨迹/神经/行为/感觉/复眼/事件记录 |
| `finalize_run(directory)` | 新轮次写入清单；应由调用方在关闭记录句柄后调用 |

预览最多扫描原文件前 64 MiB，最多返回 2000 行、约 2 MiB 结果；过大单行跳过，嵌套数组只显示少量项目。返回信息明确说明扫描前缀、抽样、无效/过大行和响应大小截断；完整原始文件可单独下载。预览不补造缺失数据。

首次实现仅进行源代码与格式静态整理。随后维护者要求“确保可以导入运行”，本次指定目录功能另行进行了隔离的保存/导入/短运行验证；证据见 `docs/功能同步验证.json` 的本次记录，不将历史测试当作当前功能保证。

## 可选的蘑菇体学习记录

平铺白名单新增 `mb_learning.jsonl`（实际块学习摘要，可用preview kind=mb_learning）和 `learning_memory.json`（最终局部突触记忆）。记忆schema_version=1，selection固定kc_type/mbon_type，edges逐条为字符串pre_id/post_id及factor；只含当前选择的完整既有正边，最多30000条。类型、边集合和factor范围严格验证，不能指定读取路径。初始记忆位于config，最终记忆同时随报告/备用文件保存；新脑载入不恢复资格迹。文件也受ZIP清单长度和SHA256核对。

## 可选的观察器文件

mb_observer.json为schema_version=1、kind=mb-learning-observer，含run_id/status/sealed、capacity/total_chunks/dropped_chunks、近期points和comparisons.before/after/comparison。points最多6000，时间单位模型秒，明确available和缺失原因；每点有实际计数/分母/因子及背景签名。捕获完整块的实际时长可能略超请求；不会分摊整数放电。比较不改变神经状态。文件紧凑保存上限30MiB，若裁剪标truncated_by_bytes并更新dropped_chunks；只读页面流式32MiB上限。仍走平铺白名单、原始字节SHA256和新目录导入，不执行包内容。
