# 工作台布局说明

## 设计约定

面向反复观察行为、调整实验参数的桌面用户，采用深灰工作台：中央固定三维视口，左侧观测，右侧属性，顶部窗口入口，底部记录状态。参考用户指定的 Blender / C4D 工作方式，不做竖屏堆叠。检查 1366×768、1920×1080 与 2560×1440 横屏。

主操作为观察三维、展开一组参数并应用。页面整体不滚动；参数面板和数据表允许局部滚动。保持原控制 ID、真实遥测、参数验证与模型时钟。图表初始收起，按需打开成可拖动、可折叠、可调整尺寸的窗口；关闭窗口只隐藏显示。布局在本机浏览器保存，可重置且不改变仿真。

加载时保留工作台骨架与原加载状态；无放电时显示原来的零值/空范围；服务错误沿用明确的连接/查询失败提示；形态数据缺失时保留其余面板；成功提交保留原确认信息。布局本身无新增权限操作，权限状态不适用。


## 日常操作

- 左侧保留复眼和脑部解剖，可点各自标题折叠。复眼去掉“它眼中的世界”和“真实复眼采样”两处文字，保留左右眼、时间和每眼小眼数。
- 右侧切换“脑模型 / 感官 / 行为 / 场景”。脑模型分为刺激输入、运动反馈、递质来源增益；展开需要的一组，修改后应用。感官区再分主要读数与环境感觉开关。
- 顶部打开地图、放电栅格、大类曲线、类型曲线、活动总览或神经元查询；底部可打开总放电率图。图表初始收起，活动总览中的统计表也可展开。
- 拖动窗口标题移动，拖右下角改变尺寸；“−”折叠为标题栏，“×”收起。再次点顶部入口可恢复。位置、尺寸、开关及折叠状态保存在此浏览器；关闭后再刷新重开仍保留原位置。
- 标题栏与尺寸把手可用方向键微调，Shift + 方向键每次 30 像素；Esc 收起最上层窗口。右侧分类可用左右方向键切换。
- 地图选中元素会切换到场景属性；点击“新增 / 移动”会自动打开地图。地图缩放布局后仍保持正方形及原坐标转换。
- “重置布局”恢复窗口和分类面板，不提交参数、不停止或重置模型。切换分类和关闭图表不清空参数草稿。

建议至少 1366×768 横屏。长表和全部展开的参数允许在面板内滚动，页面整体固定一屏，不提供竖屏堆叠布局。独立 `/brain` 继续保留完整分类活动页。更新后对主页按 Ctrl+F5；这是前端调整，不需要为它重启正在进行的实验。交付压缩包未更新。

## 验证与证据

本机实际渲染检查覆盖 1366×768、1920×1080、2560×1440，三种尺寸均无页面横向或纵向溢出。检查浮窗拖动、键盘移动/缩放、折叠刷新恢复、关闭刷新重开保留位置、Esc 与分类键盘切换、地图选择联动，以及参数草稿和应用。暂停测试实例保持脑时间 260 ms，P9 A 增益 1.1 实际应用后已恢复 1；分类统计保持 138,639 节点，78 个事件在大类和具体类型间守恒。独立脑活动页也通过检查。

加载状态通过临时延后几何/形态请求检查；空范围用不存在的类型筛选检查。测试页临时模拟形态资源 404 与活动接口失败，确认“形态未加载”及活动错误提示可见，其他场景继续显示；刷新可恢复。修复了场景表单初始化后首次遥测失败会销毁控件、导致下一次推送出错的问题。模拟只在专用浏览器测试页中发生，未修改真实模型或服务数据。

截图和机器可读记录保存在 `output/workbench`。只修改本机前端、必要的显示恢复处理和中文说明；积分精度、连接、感觉策略与交付包不变。

右侧“行为”现提供工程需要、模式、环境反应和外置气味记忆，详见 [行为与感官驱动说明](行为与感官驱动说明.md)。
