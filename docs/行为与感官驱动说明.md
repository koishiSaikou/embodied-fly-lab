# 行为与感官驱动说明

## 怎样启用

本机已加入三组扩展：综合探索、觅食学习、环境反应。先在旧网页结束并保存实验，关闭对应旧服务，再运行 `Start-Habitat.cmd`，主页按 Ctrl+F5。后端进程需要重新载入新代码；不要为了更新而关闭尚未保存的实验。右侧新增“行为”分类。

默认综合觅食场启用扩展；“行为”里关闭“启用扩展行为”可回到原来的觅食/避障策略。`--arena classic` 保留旧基线并禁用扩展行为。交付 ZIP 未更新。

## 能观察到什么

| 行为 | 驱动与表现 |
| --- | --- |
| 综合探索 | 按当前需要和感觉组合选择方向，实际 P9 放电仍决定行走幅度 |
| 优先觅食 | 饥饿增强食物气味作用，甜味接触后停留，饱腹后离开；两类气味偏好影响选择 |
| 优先寻水 | 按左右触角湿度差寻水，足部进入水源后停留并降低口渴代理值 |
| 明暗偏好 | 可选趋光、趋暗，或趋向适光但回避超过阈值的强光 |
| 温度舒适趋向 | 朝左右触角温度更接近设置值的一侧转向；危险高温仍触发原来的后退 |
| 逆风追踪 | 有气味时结合风向代理修正行走；地图顶部箭头标明风吹向 |
| 局部气味搜索 | 气味明显减弱或降过检测阈值后短时摆扫，重新闻到较强气味时退出 |
| 视觉惊逃 | 真实复眼视野占据迅速扩张时短时后退转向，带冷却间隔 |
| 休息 | 疲劳达到阈值或手动选择时停止行走，脑计算继续，疲劳逐渐下降 |
| 前足清洁 | 第一种动作程序为右前足抬到头部附近摆扫，另外五足支撑；先短暂站稳再开始 |

七个可选模式为综合探索、优先觅食、优先寻水、跟随明暗偏好、自由探索、休息、前足清洁。危险、实体接触和迫近惊逃可打断目标动作；普通复眼避障沿用原工程反射。模式是行为偏好，仍受对应开关、感觉是否可用和安全反射限制。

场景编辑新增“凉区 / 冰块”，三维是冰块，地图是雪花；它提供降温代理场，默认七区布局不变。原来的水、危险、食物和明暗区继续使用真实触角/足部位置采样。

## 需要值与演示

饥饿、口渴、疲劳、清洁负荷都是 0–1 的工程状态，不是生理测量。右侧有实时进度条，“设置需要值 / 行为演示”可手动设定，暂停时也能应用。

- 看寻水：选“优先寻水”，开启湿度/水源反馈和寻水行为，设较高口渴，把水源放在前方空地。
- 看饱腹离开：选“优先觅食”，靠近食物后观察饥饿下降；设为接近 0 可快速观察离开。真实足部甜味接触仍给糖 GRN 输入，与是否选择进食分开。
- 看休息：选“休息”；也可以在综合探索中把疲劳设到 0.9。恢复其他模式即可重新选择目标。
- 看清洁：先让果蝇在空地站稳，选“前足清洁”。该程序受全局运动反馈开关、反馈增益 0 和强制断开输出的限制；避障反射可能先执行。程序通过关节执行器动作，没有移动或重置真实 qpos。
- 看温度/明暗：在地图放置亮区、阴影或冰块，展开环境反应参数，调整偏好与阈值；保留相应感觉开关。
- 看惊逃：保持视觉驱动开启，在视野前方突然放入较大造型；只有复眼实际采样形成足够扩张信号才会触发，不按物体名称或坐标直接判定。

初始需要值为饥饿 0.65、口渴 0.4、疲劳 0.05、清洁负荷 0.1。所有变化按模型时间累计；暂停不增长。示例参数包括饥饿每模型秒增加 0.004、进食按甜度降低，口渴每秒增加 0.005、饮水停留每秒降低约 0.3，疲劳/清洁负荷还随实际运动路程增加。关闭需要状态会冻结这四项；手动模式仍可使用。

## 觅食学习是什么

这里实现的是外置的两通道气味价值记忆：糖气味与果味各有一个 -1 到 1 的价值，初始都为 0.5。实际触角气味形成约 1.5 模型秒衰减痕迹，进食时的真实甜味接触提供奖励，苦味提供负反馈；价值再改变后续气味权重和 P9 刺激。学习速率可调，自动更新按模型 dt 缩放，与电脑计算快慢无关。

展开“觅食学习与记忆”可看到两个价值、更新次数和最近奖励。奖励 +1 / 惩罚 −1 是显式训练干预，作用于当前气味痕迹；没有有效痕迹时不会更新。想做对照时，暂停、改变奖励、继续观察价值和后续转向；“清空气味记忆”恢复初始价值和空痕迹。“恢复行为设置”只恢复开关和参数，不清记忆；新一轮会清空记忆和需要值。

这是整个仿真代理新增的学习层，全脑仍使用原来的统一 LIF 与连接权重。它不表示已实现蘑菇体可塑性、多巴胺奖励通路、受体动力学或生物级代谢。清洁是工程关节程序，饮水是几何接触后的停留；风是均匀方向代理，不会吹动物体，也没有模拟气味随风输运。

## 记录与复现

- `config.json` 保存初始行为设置。
- `behavior.jsonl` 每个计算块保存设置、需要值、两种气味价值、痕迹、奖励、状态和原因；外层 `time_s` 是整轮模型时间，`active_model_seconds` 是扩展策略累计启用时间。
- `events.jsonl` 保存行为设置、需要值干预、训练奖励是否实际更新、清空记忆及原请求。
- `senses.jsonl` 继续分别保留原始和启用后的输入，包括风的方向、强度和相对朝向。
- `report.json` 保存最终记忆/需要值、修订号、配置和清洁 IK 规划误差。

测试证据在 `output/behavior`。规则、动作和学习效果已做短测；没有把这些结果当作真实果蝇行为的生物学验证。
