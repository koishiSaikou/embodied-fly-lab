# 实验保存、本地查看与分享复现

本功能保存实验数据和配置，供本机查看、打包给别人、在同一项目和模型版本下重新实验。**不保存完整脑/身体中间状态，不是从某一帧接着运行的存档。**

## 保存一轮实验

在主实验场点击“结束并保存”，或在启动控制台按 Ctrl+C，等待收尾完成。每轮使用独立的 `output/habitat/时间戳/` 目录。运行中和保存中有 `.recording` 标记；未完成保存时不能导出，避免导出仍在变化的数据。

| 文件 | 内容 |
| --- | --- |
| `config.json` | 初始环境、脑控制、行为初值、种子、时长、版本、依赖、时间单位 |
| `final_config.json` | 本轮结束时的环境和参数、最终外置需要/气味偏好，供新实验复用 |
| `reproduction.json` | 初始条件重放与最终配置新实验的两种方案及限制 |
| `events.jsonl` | 实际应用的设置修改、奖励及相应模型时间 |
| `trajectory.csv` | 身体轨迹、感觉和控制读数 |
| `neural.jsonl` | 脑块汇总，以及请求采集时已有 worker 活动事件和截断标记 |
| `behavior.jsonl`、`senses.jsonl`、`retina.jsonl` | 行为、感觉与实际复眼采样 |
| `report.json`、`monitor_snapshot.json` | 结束报告、最后网页状态；并非完整仿真检查点 |
| `arena.png`、轨迹/占据图、可选 `arena.mp4` | 已生成的图片和录像 |
| `manifest.json` | 包格式、来源、逐文件大小与 SHA256 清单 |

神经记录不保证包含全脑所有放电：worker 每块活动事件有上限，`events_truncated` 表示该块被截断；旧实验的 `neural.jsonl` 可能仅有汇总。复眼是周期采样，不是每个物理积分步的原始摄像流。

## 保存到指定目录

主页面保留原“结束并保存”按钮，仍保存到项目的默认记录目录。旁边新增 **“另存到…”**：

1. 点击“浏览目录…”打开 Windows 文件夹选择窗口，也可手动输入现有目录的绝对路径，例如 `D:\FlyExperiments`。支持中文和空格；文件夹须事先存在并可写。
2. 点击“结束并另存”。服务器先检查目标目录，再结束本轮、完成默认记录和清单，最后把完整实验 ZIP 保存到选择的目录。
3. 等待“另存完成”及实际 ZIP 路径。每次创建独立文件名，不覆盖已有文件；默认记录和默认导出缓存仍保留。

另存由服务器负责，关闭网页不会取消已受理请求；关闭启动控制台或强制结束进程仍可能中断保存。目录不可写、磁盘空间不足或原记录未完成时会显示错误，可以进入该轮记录页再次点击“另存到…”。记录页的另存只复制已有实验包，不启动或停止仿真。

目标目录中得到的是 **ZIP 文件**，不移动运行中的原始记录，不是更换程序安装目录，也不包含 Python 环境或连接组大文件。目录选择窗口出现问题时可直接输入路径。

## 本地查看

主实验场底部有 **“实验记录 · 导入与分享”** 入口，打开 `/records` 页面。左侧选择实验，右侧可查看：

- 结束状态、模型时长、随机种子、版本与配置。
- 实际轨迹、神经块放电率、行为/感觉/事件预览。
- 初始与最终参数、外置气味偏好和需要状态。
- 已保存的图片、录像，以及允许下载的原始数据文件。

预览为有界读取和抽样，页面会提示只扫描前段、跳过大行或返回字节限制。它不改变原文件；需要完整数据时下载原 CSV/JSONL。神经曲线按实际 `chunk_spikes / chunk_ms` 计算，不能据此推断完整逐神经元历史。

不想启动仿真时，双击根目录 **View-Records.cmd**。控制台会打印查看地址，默认从 `http://127.0.0.1:8476/records` 寻找可用端口。此查看器只使用已安装的身体/网页环境，不加载 MuJoCo、PyTorch 或脑模型，不需要 GPU。它仍需项目的 `.venv` 和网页资源，不是单独拷贝一个 HTML 就能运行。

```powershell
.\View-Records.cmd
# 自选端口
.\View-Records.cmd --port 8490
```

关闭查看器控制台时按 Ctrl+C；不会停止另一个端口上的仿真。

## 给朋友分享

1. 先结束并保存实验，等待保存完成。
2. 在记录页选择该轮，点击导出实验包，下载 ZIP。
3. 将 ZIP 发给朋友。朋友先准备支持该功能、模型和依赖相匹配的本项目，再打开记录页面导入。
4. 导入会校验格式、文件名、大小和 SHA256，在 `output/habitat/imported_时间_随机值/` 创建新记录；不会覆盖朋友原有实验。

主页面顶部的 **“导入实验”** 可直接进入导入区域。“导入后运行…”会先完成导入并选中新记录，再显示运行选项；用户确认“初始条件重放”或“最终配置与学习记忆新实验”后才开始运行。它不会自动结束正在运行的其他实验；请先结束当前轮并等待保存完成。独立查看器提供启动命令，不直接接管仿真。

包内包含配置、已有数据、图像/录像与来源许可，不包含 Python 环境、原始连接大表、权重缓存、脑工作日志或任意本地文件。配置和旧报告中的历史路径可能作为文字保留，导入不会将这些路径作为执行参数。分享前可以在“全部文件”中查看实际包含内容。

导出旧实验会在 ZIP 内生成清单和缺少的来源附件，不改写旧实验目录。导出的 ZIP 缓存在 `output/experiment_exports/`；导入暂存放在当前项目输出目录，成功后才原子入库。包格式细节见[实验包格式](实验包格式.md)。

## 导入后如何复现

导入本身只保存数据，不执行仿真。可在主实验场保存收尾后，选择两种操作：

| 模式 | 行为 |
| --- | --- |
| 初始条件重放 | 使用原初始环境、脑/行为参数、种子和初值，按原模型时间重新应用已记录的设置事件。原连续实验的结束时长在 0.02–3600 秒内时，默认使用该时长；超过上限或无法确定时仍连续运行，须手动结束 |
| 最终配置新实验 | 使用结束时的环境、脑参数、外置需要和气味价值，重新初始化身体和脑；不重放过去的设置事件 |

两个模式都创建独立新轮次，保留源记录。实验还在运行或收尾时按钮不可用，也不会自动结束当前实验。暂停只保留当前内存状态，不满足开始另一轮的条件。

独立查看器不拥有仿真，不能从该服务直接启动；页面会提供可复制命令。例如在项目根目录执行：

```powershell
# 替换为实际导入轮次编号
.\Start-Habitat.cmd --experiment output/habitat/imported_轮次编号

# 以结束时配置和气味偏好开始新实验
.\Start-Habitat.cmd --experiment output/habitat/imported_轮次编号 --experiment-mode final

# 明确不重放历史设置事件，只使用初始配置
.\Start-Habitat.cmd --experiment output/habitat/imported_轮次编号 --no-replay-events
```

命令行导入时，种子、实验时长、场景和脑控制以所选方案为准。包内的端口、主机路径、输出位置、可执行命令不用于运行。无脑基线应通过原 `habitat.py --no-brain` 的无监控入口使用，当前完整网页实验场需要脑模式。

## 复现的边界

- 已记录且明确不匹配的项目、连接组、注释、身体和依赖版本会拒绝运行；新记录还保存关键源码文件的 SHA256，摘要不匹配时拒绝运行。这不是整个仓库或模型大文件的完整校验。旧实验缺少版本或摘要时给出兼容性未知提示。
- “版本号相同”不代表代码完全相同。带有旧源码摘要的实验仍须使用匹配的代码运行；重新导出不会把旧摘要改造成新摘要。应将本次更新后的源码提供给朋友，并用该版本创建要复现的实验。
- 相同条件不保证不同显卡、驱动或数值库逐步产生完全相同的神经事件。这里保证的是条件和记录可交换，不是逐位确定性或中途状态恢复。
- 外置气味价值可以复用，不代表恢复了全脑学习；脑膜电位、延迟电流、随机数中间态、身体完整状态和行为计时器仍重新初始化。
- 强制杀进程、断电、磁盘满仍可能使本轮只留下部分文件；清单/哈希不是掉电持久性保证。没有引入此前暂缓的长期资源管理。
- 已公开的 `v0.1.0-alpha.1` ZIP 不会自动改变。使用这些新增入口需要更新本机源码；本轮没有重建或上传新的运行包。首次实现仅做静态核对；随后维护者要求“确保可以导入运行”，另行进行了隔离的保存、导入与短时运行验证，具体结果见 `docs/功能同步验证.json` 中本次记录，不代表全量功能、长时间或性能验收。

旧 Body/Coupled/Activity 入口的原固定文件名和中断保存缺口没有在本功能中统一改造。新分享和复现入口面向主 Habitat 的实验记录，不将旧模式报告冒充为可复现的 Habitat 场景。

虚拟神经干预的初始/最终协议与模型时间变更事件也进入实验包。初始条件重放包含干预事件；最终配置新实验从模型时间0重新使用最后配置的完整窗口。详情见[虚拟神经干预说明](虚拟神经干预说明.md)，它不是旧脑状态或半段刺激的恢复。

## 局部突触记忆

蘑菇体模块启用后，实验还保存初始/最终控制、教学值、完整局部边因子和每块学习摘要。初始条件复现使用初始因子及已应用教学/设置/重置事件；最终配置复现把最终因子载入新脑，资格迹清零，不是中途检查点。已初始化模块缺失最终因子时拒绝最终复现。边ID/类型/完整集合及关键源码版本必须匹配，未知边或缺边拒绝导入。当前源码变化会使之前记录的关键哈希不同，原有兼容检查会拒绝此类旧条件运行；旧记录仍可查看。见[蘑菇体局部学习说明](蘑菇体局部学习说明.md)。

## 学习观察器随包查看

新版保存白名单增加mb_observer.json（有界近期模型时间块、前后捕获窗口和比较）。在历史“蘑菇体学习”分类可打开同一图表只读查看，朋友导入后也可使用独立查看器，不启动脑或身体仿真；旧记录没有该文件时不补造。完整新块遥测另见mb_learning.jsonl。观察窗不属于刺激命令，不重放为新的模型结果。见[观察器说明](蘑菇体学习观察器说明.md)。
