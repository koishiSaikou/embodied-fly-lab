# 蘑菇体学习观察器

观察器把同一个实际脑积分块的气味输入、KC 放电、教学信号、资格迹、局部突触因子和 MBON 响应对齐在模型时间上。它读取计算结果，不控制刺激、不推进脑或身体时间，也不自动运行条件学习实验。

## 打开和读取

正常结束保存旧轮，重启新版实验场。点击顶部“学习观察器”，或右侧“局部学习”中的入口。窗口可以拖动、折叠和调整尺寸，沿用桌面横屏工作台。

先在“局部学习”启用模块并应用，等待实际积分。默认关闭且从未初始化时没有局部遥测，图中留空，不画成零。模块已经初始化后，即使关闭总开关或冻结可塑性，也继续统计选中 KC/MBON 的真实放电；关闭时因子被绕过、资格迹不演化，存储因子仍保留。

| 轨道 | 数据与单位 |
| --- | --- |
| 气味 | 本块输入的糖/果香强度，0–1；已经过感官开关门控 |
| KC 平均率 | 选中全部 KC，以及固定糖/果香编码组的平均 Hz；包含静默成员 |
| 教学信号 | 本块实际送入模块的外部教学标量，0–1；不是 DAN 放电率 |
| 资格迹 | 块末资格迹的平均值和最大值，0–1 |
| 更新后增益 | 本块更新后的 factor 平均值和最小值，下一块使用；不是绝对连接权重 |
| MBON 平均率 | 选中全部 MBON 的实际群体平均 Hz，包含静默成员 |

放电率分母是实际块模型秒数与相应神经元数量；空编码交集没有合法分母，返回空值。糖/果香编码组可能重叠，不可把两组简单相加视为全部 KC。右侧直方图按 10 个区间统计局部边因子，最后一个区间包含 1，所有柱子计数之和等于当前局部正边数。

本块 MBON 响应来自本块计算时使用的权重，不能当作块末刚更新因子的即时结果。气味强度也不是视觉/嗅觉完整天然神经通路的活动。

鼠标移到曲线上可查看实际块起止时间、各指标与修订号。线段只覆盖真实块的时间范围；缺失块、未初始化数据和时间间隙留空，不插值或补零。暂停期间没有新积分，曲线不前进；暂停后改设置，旧块仍保持原设置身份。

## 捕获训练前后窗口

1. 先让目标气味与其他输入保持相对稳定，在停止教学、冻结可塑性的状态下运行至少所选窗长，点击“捕获前窗”。
2. 在原局部学习面板允许可塑性、施加手动或糖接触教学，进行你要研究的配对。手动教学是持续门控，结束配对记得点 0。
3. 再次停止教学并冻结可塑性，在相同目标气味和背景设置下运行至少所选窗长，点击“捕获后窗”。
4. 比较 KC/MBON 平均率、各 MBON 的 Hz、因子和输入差异。面板显示实际起止、请求/实际窗长、完整块数、兼容性与警告。

捕获支持 0.2、1、2、5 模型秒。使用最近的**完整实际积分块**，实际长度可能略长于请求；不会把一个放电按时间比例拆成部分放电。窗口放电率按累计次数与实际时长计算，不把不同长度块的 Hz 简单平均。

以下情况会拒绝捕获：没有足够完整模型时间、缺局部遥测、时间缺口、窗内目标/编码/背景设置变化，以及设置改变后仍想使用变更前旧块。暂停后重置记忆或修改设置，须恢复积分并等待足够的变更后模型时间再捕获。

前后窗必须顺序正确且不重叠。比较允许前后可塑性开关不同，其他局部参数、选中 MBON、编码/重置身份、场景/行为修订、脑刺激与感觉开关、干预身份及实际阶段不同，会标记不可直接比较。一个定时干预协议从等待到生效再到结束，也不能混为同一背景。实际气味、P9/糖输入、教学或窗长不同时给出相应提示。

即使参数可比较，也只能得到观察性结果：脑和身体初态、随机输入及尚未衰减的电流可能不同，不能据此认定所有差异都是学习造成的。正式研究仍需要独立的配对/不配对等对照与重复实验，本观察器不代替这些实验设计。

## 保存、朋友导入与历史查看

结束保存时增加 `mb_observer.json`：保存有界的近期实际块、两个捕获窗、前后比较及截断信息。它随实验 ZIP 的白名单、长度和 SHA256 校验一起导出、导入。历史页的“蘑菇体学习”分类可打开只读观察器，沿用同一图表；独立 `View-Records.cmd` 入口不需要加载脑模型、PyTorch 或 MuJoCo。

历史观察器只读取所选记录白名单内的 JSON，不执行包内代码、不加载路径或 pickle，不提供捕获/教学按钮功能，也不会把旧图当作新仿真的实时数据。老记录没有观察器文件时仍可查看已有记录，不补造缺失遥测。

在线缓冲和前端最多保留最近 6,000 块；默认 20 ms 块对应约 120 模型秒。关闭、折叠窗口或隐藏页面会停止轮询，服务端仍按实际块记录；重开补取保留的数据，过旧数据明确标为截断。保存文件使用紧凑 JSON，超过 30 MiB 时继续裁掉最旧整块并标记，保留捕获摘要。只读页面拒绝超过 32 MiB 的文件。完整新逐块遥测另在 `mb_learning.jsonl` 中，不受观察器近期缓冲裁剪影响，但仍受原有记录与实验包大小边界约束。

捕获仅在本轮运行中允许（可以暂停）；进入保存和结束阶段后封存，不能晚到修改已生成清单的记录。捕获是观察操作，不进入刺激设置重放；复现新轮会建立新的观察器，不把来源曲线伪装成新结果。

## 开发接口

- `mb_learning_runtime.py`：只在已有块计数之后缓存小型 `observation`；不修改学习方程、因子更新或 RNG。带 captured controls，而不是用后来设置改写旧样本。
- `brain_worker.py`：为 observation 加上真实起止脑时间、当块设置/重置修订；暂停管理 RPC 不重打旧读出的时间戳。
- `mb_observer.py`：纯标准库有界缓冲、模型时间窗口加权统计、条件比较与封存保存。`habitat.py` 逐成功块 append，成功设置后要求新数据，保存前 seal。
- `GET /api/mb-observer?after_seq=0&limit=600`：seq 游标分页，含截断和是否还有后续页；每次最多 600 块。
- `POST /api/mb-observer/capture`：仅 `slot=before|after`、`duration_s`；同源、有限请求，不能发送仿真命令。
- `web/mb_observer.js/css/html`：实时与历史共用图表；历史通过 `/api/experiments/<id>/file/mb_observer.json` 白名单取文件。

数值、纯逻辑、数据传递与静态核对范围见[观察器验证记录](学习观察器验证记录.json)。本轮没有进行完整全脑 CUDA、身体、浏览器、性能或长时验收，未更新旧 Release/交付包。
