# 虚拟神经干预

此功能用于提出和比较模型中的回路假设：选择神经元，定时增加外源刺激或暂时阻断放电，再观察目标群、全脑和 P9 输出的变化。它不是已经校准到真实动物的光遗传学实验，单次行为变化也不等于证明真实果蝇的因果机制。

## 如何操作

重新启动新版主实验场，在右侧属性分类中选择 **“神经干预”**。

1. 选择“刺激”或“静默”。刺激频率表示每个目标增加的外源 Poisson 输入，范围 0–1000 Hz，与原输入相加后封顶 1000 Hz。
2. 输入完整 FlyWire ID，或选择精确 `cell_type`。ID 可以从现有神经元查询中复制，必须保留为完整的 18 位数字字符串；类型区分大小写，不进行模糊匹配。
3. 点击“检查目标”，确认匹配数量和列出的 ID。检查目标不推进模型或触发干预。前端手动输入最多 100 个不同 ID；按类型可选择最多 10,000 个目标，页面只列出前 20 个。
4. 设置开始时间与持续时间，点击“应用到本轮”。时间单位是**模型秒**，不是电脑实际等待的秒数；持续范围为 0.0001–3600 模型秒。
5. 查看下方真实积分读出。计划窗口、首次实际作用、最近实际作用分别显示；只有实际执行过积分步才会产生真实作用时间。
6. 到期后干预自动结束。点击“取消干预”会取消当前协议以及未来尚未开始的窗口，不重置脑或身体。

首版每轮只保留一个协议；新的协议替换旧协议。支持加载当前协议为草稿，但实时更新不会覆盖尚未应用的编辑。输入 ID 时不要使用省略号、科学计数法或 JavaScript 数字转换。

## 时间与真实生效

主程序在约 20 模型毫秒的控制块边界接收设置，脑内按 0.1 模型毫秒积分步执行。窗口为 `[开始, 结束)`，按纳入窗口的积分步时间量化。

“下个控制块”使用提交时最近收到的模型时间，不保证从那个过去的时刻开始作用。请求在某个脑块计算期间到达时，需要等待后续控制边界；短窗口可能在登记前已经到期。需要精确刺激时，选择一个留有余量的未来模型时间。

- “配置量化窗口”说明计划覆盖的积分步范围。
- “首次/最近实际作用”来自真正执行的积分步；没有执行则显示“—”。
- “本块有效积分步数”说明最近整个脑块中有多少步受到干预。
- 协议修订号与实际积分块修订号不一致时，界面会明确提示等待确认，旧读数不表示新协议已经生效。

暂停时可以登记、替换或取消协议，但不会推进身体或脑时间；恢复运行后才有新的实际积分读出。已经过去的积分步不会补做。

## 两种干预的模型含义

| 方式 | 实际操作 | 解释边界 |
| --- | --- | --- |
| 刺激 | 在选定步给目标添加外源 Poisson 频率，复用模型原有采样器，保持普通目标已有不应期的附加输入门控 | 频率不是目标放电率；不模拟光敏通道、光强或真实刺激器动力学 |
| 静默 | 每步传播前清除目标上一刻放电，并在步前/后夹持目标电位、局部电导、输入延迟和输出放电 | 已排队进入其他神经元的电流仍可能继续传播；不是物理损伤或删掉连接 |
| 取消/到期 | 后续积分不再施加上述干预 | 不恢复干预前的膜电位、网络活动、随机状态或身体轨迹 |

P9 输出经过原有平滑及身体控制器。因此，即使 P9 的本块放电已为 0，身体也不一定立刻静止。全局递质增益和原始连接权重仍按现有规则处理；本功能不修改磁盘权重、上游方程或训练全脑。

## 应该比较哪些结果

目标总放电率以**整个实际脑块时长**为分母；每目标平均率再除以全部选中神经元数量，包含没有放电的目标。如果窗口只覆盖脑块的一部分，数值仍是整个块的平均，不能当成仅窗口内的瞬时率。

建议先做独立的正常条件、目标干预和合适的随机目标对照；比较目标读数、P9 输出及实际行为。改变过网络状态后直接取消，并不构成与全新对照完全相同的条件。自动批量对照、统计推断、同时执行多个协议及特定连接削弱尚未加入本版。

## 保存、分享与重新运行

- `config.json` 保存初始协议及完整解析目标列表。
- `events.jsonl` 保存协议变更的模型时间、完整解析目标列表，以及真实脑块阶段记录。
- `neural.jsonl` 的每块 `intervention` 保存真实执行步数、作用时间、目标数量和放电统计；页面摘要只列前 20 个目标。
- `report.json`、`final_config.json` 保存最终协议与最后的实际读出。完整解析列表不受网页前 20 项限制。
- 初始条件重放恢复初始协议并按模型时间重放变更事件。最终配置新实验复用最后配置的**整个时间窗**，时间从新一轮 0 开始，并非恢复旧窗口执行到一半的状态。
- 运行前检查目标在本地模型中确实存在；无脑模式拒绝神经干预。源码/数据不匹配仍按既有兼容性规则拒绝，不改写旧记录的摘要。

导入导出仍使用原实验 ZIP，详见[实验保存与分享说明](实验保存与分享说明.md)。旧 Release 运行包没有自动更新；本地源码改动保持未提交、未推送。

## 当前验证范围

对原始 `TorchModel` 的 8 节点 CPU 小网络完成数值核对：未干预时五个状态张量、放电计数和随机状态与原调用相同；定时静默、传播阻断、到期恢复、额外刺激、频率上限、不应期、取消和精确时间边界均通过。证据见[神经干预验证记录](神经干预验证记录.json)。

这不是完整连接组、CUDA、三维身体或浏览器交互的运行验收；没有启动或控制已有实验，也没有进行长时间或性能测试。
