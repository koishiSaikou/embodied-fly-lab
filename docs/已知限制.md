# 已知限制

适用于目标 0.1.0-alpha.1 Demo，不是正式完整产品。

| 范围 | 当前边界 |
| --- | --- |
| 运行平台 | 当前安装/运行路径面向 Windows x64，脑模式需 NVIDIA CUDA；不承诺其他平台/显卡已验证 |
| 路径与界面 | MuJoCo 当前要求英文/ASCII 项目路径，允许空格；工作台面向桌面横屏，不适配竖屏 |
| 速度 | 全脑积分通常慢于真实时间，以页面模型时间为准；不是显示刷新率代表的大脑计算速度 |
| 神经模型 | 连接组规模不等于生理完整：统一简化 LIF、预测递质来源增益，无完整受体/浓度动力学，也没有全脑突触可塑性 |
| 身体控制 | 步态 CPG 近似运动层，没有完整腹神经索 VNC；没有恢复全部自然行为或飞行 |
| 感官与学习 | 实际复眼采样结合工程视觉风险；其他感觉含代理场/规则。气味偏好学习是外置记忆，非全脑自己学会全部行为 |
| 解剖显示 | 全模型参与活动计算；三维只展示已下载的 16 个骨架和 78 个静态脑区，静态形状不是活动 |
| 错误恢复 | 脑期限用于多感官 Habitat，旧 Coupled/Activity 通信尚未迁入；不为任意驱动/磁盘阻塞提供抢占保证。新一轮不是膜电位检查点恢复 |
| 长时间运行 | 内存轨迹/统计和磁盘记录仍会持续增长，保护功能按维护者要求暂缓；自行关注可用资源，结束时保存，不自动删历史记录 |
| 许可与数据 | 程序 GPL-3.0-or-later 不替所有资产授权；FlyWire 数据含 NC 条件，混合 JSON 不能统一宣称可商用 |
| 版本/交付 | 0.1.0-alpha.1 为 Pre-release，提供源码及更新后的 Windows 运行包；两个外部 wheel 须单独下载。本次未运行新仿真测试，不以全产品验收作为 Demo 发布条件 |

维护者要求本轮不新增/运行测试，因此不能把已有旧验证记录当作最新版本的全面保证。工具和历史检查可以继续保留，后续是否执行由任务范围决定。
