# 启动与停止

本页适用于 0.1.0-alpha.1 源码和 Windows 运行包。源码按 [源码安装说明](源码安装说明.md)，运行包按 [交付包说明](交付包说明.md) 安装。按用户后续要求，功能修复也已备份后同步到现有本机项目，验证见 [功能同步验证](功能同步验证.json)；维护者已授权本版本运行包更新，旧日期 ZIP 保留。

## 日常启动

双击 `Start-Habitat.cmd`。控制台保持打开，程序会：

1. 检查需要的项目环境和输入文件，缺失时给出安装/下载提示。
2. 从默认端口 8472 开始寻找空闲端口；如果已有实例占用，会选择另一个端口并打印实际地址。
3. 启动网页三维实验场。隐藏 MuJoCo 原生窗口不再阻止浏览器打开；HTTP 服务和场景就绪后，调用系统默认浏览器打开该实例地址。
4. 加载脑模型时网页显示载入阶段、等待秒数和期限。等待模型完成初始化，再进行实验。

默认持续运行，不会在 30 秒模型时间自动停止。浏览器关闭不会停止仿真。相同服务内保存后重开一轮不会再次打开浏览器。

默认浏览器未配置、打开失败或系统未确认打开时，仿真继续运行，控制台给出实际地址供手动打开。不能总是假定当前实例使用 8472，以启动控制台中的地址为准。原来已运行的实例不会被接管或停止。

## 停止与重开

- **暂时停住**：网页点击“暂停”，稍后“继续”，脑与身体状态保留。
- **结束当前一轮**：网页点击“结束并保存”，等待保存完成；网页服务仍在。
- **重新开始**：保存后点击“开始新一轮”，恢复本轮初始配置并初始化新的脑/身体，创建新记录目录。
- **完全退出**：在对应启动控制台按一次 `Ctrl+C`，等待记录保存、脑子进程和网页服务关闭。看到退出提示后再关控制台。

启动器收到 Ctrl+C 会等待仿真子进程正常收尾，不会因为父进程先中断而立即杀掉正在保存的仿真。若 Ctrl+C 恰好发生在保存阶段，会记住退出请求，完成当前保存后关闭服务。加载脑模型时取消也会回收本次创建的脑进程。

若 Windows CMD 额外询问“终止批处理操作(Y/N)?”，等待保存完成后按 Y 结束批处理即可。

请不要把直接关闭窗口、任务管理器强制结束或停电当作正常保存；这些情况不在本次优雅退出保证内。脑进程无响应期限、磁盘不足和所有清理错误隔离仍是后续稳定性工作。

## 常用参数

在项目根目录 PowerShell 执行：

```powershell
# 不自动打开浏览器，自己打开控制台打印的地址
.\Start-Habitat.cmd --no-browser

# 使用确定端口；被占用则明确报错，不会偷偷改成其他端口
.\Start-Habitat.cmd --port 8480

# 关闭录像，保留实验数据记录
.\Start-Habitat.cmd --no-video

# 运行 10 秒模型时间后保存，网页继续保留
.\Start-Habitat.cmd --seconds 10

# 有限短测：保存后连网页服务一起退出
.\Start-Habitat.cmd --seconds 0.2 --exit-when-finished --no-browser --no-video

# 原仿真入口的附加参数继续传递
.\Start-Habitat.cmd --arena classic --no-vision --seed 7
```

`--seconds 0` 表示持续运行；有限场景时间范围为 0.02–3600 模型秒。`--exit-when-finished` 只用于有限场景实验。指定 `--port` 必须在 1024–65535；默认端口最多向后检查 50 个，找不到则要求明确另选。

指定目录：主页面保存按钮旁新增“另存到…”，可浏览或手输现有绝对目录；结束并收尾后由后端另存唯一 ZIP，保留默认记录，不覆盖已有文件。顶部“导入实验”进入 ZIP 导入；“导入后运行…”会先导入并选中记录，再由用户确认初始重放或最终配置新实验。

## 记录查看与导入条件

`View-Records.cmd` 仅运行本地记录查看器，不加载仿真或 GPU；实际地址见控制台，默认从 8476 选空闲端口。主实验场也可从底部进入 `/records`。

```powershell
.\Start-Habitat.cmd --experiment output/habitat/实际轮次编号
.\Start-Habitat.cmd --experiment output/habitat/实际轮次编号 --experiment-mode final
```

前者重建初始条件并按模型时间重放设置事件，后者以最终环境、参数及外置偏好开始新实验。模型时长和种子以导入条件为准，不加载包内的路径、端口或可执行命令。详见[实验保存与分享说明](实验保存与分享说明.md)。

## 其他入口

| 入口 | 用途 |
| --- | --- |
| `Start-Body.cmd` | 单独身体/CPG 原生窗口，默认 3600 模型秒，无需脑环境 |
| `Start-Brain.cmd` | CUDA 脑刺激自检，输出结果后退出，控制台保留 |
| `Start-Coupled.cmd` | 原有固定刺激脑—身体演示，默认 30 模型秒，不是多感官场景 |
| `Start-Activity.cmd` | 原有耦合演示及独立脑活动页，默认 300 模型秒；网页默认端口从 8470 开始选择 |
| `Check-Environment.cmd` | 源码环境、身体与 CUDA 诊断 |

源码的五个 Start 包装器通过 `Start.cmd` 调用 `launcher.py`；运行包调用隔离解释器及 `delivery/launch.py`，再转入同一 `launcher.py`。附加参数和退出码统一传递。身体/耦合演示可加 `--seconds 0.1 --headless` 做无原生窗口短测。运行包已按本版本重新构建；本轮未执行这里列出的仿真验证命令。

## 日志与故障

Python 启动器运行后，每次各自保存 `output/launch/时间戳_模式.log` 和同名 `.json`，包含执行命令、实际 URL、退出状态和错误；若两套 Python 环境均不存在而无法进入启动器，CMD 会直接保留安装提示。实验完整记录仍在 `output/habitat/本轮目录/`，脑工作日志仍在该轮 `brain_worker.log`。这些目录被 Git 忽略。

- 缺环境或文件：按提示运行 `Setup.cmd` 或准备资源，见源码安装说明。
- 原生包/DLL/CUDA 错误：运行 `Check-Environment.cmd`，查看对应诊断与本轮脑日志。
- 端口冲突：默认启动会换端口；显式指定的端口则报错，改用另一个端口即可。
- 正常完成退出码为 0，用户 Ctrl+C 的共享启动器退出码为 130；其他非零值表示需要查看日志。交互式 CMD 会保留窗口，不会一闪而过。
- 命令行/自动化不需要最后“按任意键”时，可仅在当前终端设置 `$env:FLYWIRE_NONINTERACTIVE='1'`。此开关不改变模型或保存行为。

多感官实验场已经增加首次脑加载 300 秒、每次脑计算 30 秒的等待期限，暂停除外。错误后保留网页和部分记录，须手动重开；参数与故障记录位置见 [异常处理与恢复说明](异常处理与恢复说明.md)。旧固定刺激的 Coupled/Activity 演示不在这次超时改动范围。

## 本机验证

验证范围与结果见 [启动验证记录](启动验证记录.json)。包括带空格路径的实际 CMD 调用、参数/错误码传递、端口占用、真实 CUDA 闭环、无窗口自动打开机制、重开不重复开页、禁止自动打开，以及隔离控制台中的 Ctrl+C。

自动打开机制测试拦截了操作系统的浏览器调用，在回调中访问真实 HTTP 场景并核对地址；没有为测试启动桌面浏览器。Windows 中断测试使用新建的隐藏控制台并核对进程列表，未向其他实例发送控制事件。
