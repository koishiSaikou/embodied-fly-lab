## 原生依赖的边界

不能把 wheel 顶层许可当作内部所有二进制的统一许可。NumPy/SciPy 附带 OpenBLAS 及 GCC 运行库声明与 GCC Runtime Library Exception；原文一同保留。Pillow 的 FreeType 采用其 FTL 路径，保留 FreeType Project 与其他图像库声明；不把文档提及的 XZ 命令行脚本推定为本包实际程序。PyOpenGL 的 GLE 采用其原 COPYING 允许的 IBM source 许可路径，并保留 COPYING.src 与原声明，不强行改成 GPL-only。

MuJoCo 3.9.0 wheel 自带第三方许可明确采用 `EIGEN_MPL2_ONLY`，保留其 MPL 及其他原声明。[MuJoCo 源码和构建配置](https://github.com/google-deepmind/mujoco/tree/3.9.0)及[固定依赖文件](https://github.com/google-deepmind/mujoco/blob/3.9.0/cmake/MujocoDependencies.cmake)给出 Eigen 提交 `ea13a98decd497a8c5588fb5de71b57bcf10d864`；对应[Eigen 源码](https://gitlab.com/libeigen/eigen/-/tree/ea13a98decd497a8c5588fb5de71b57bcf10d864)可供获取/修改，未由本项目修改。此次环境访问 GitLab 返回 403，记录的是 MuJoCo 固定构建配置的来源依据，并未谎称已下载 Eigen 存档。certifi 保留其 MPL/MIT 及随 wheel 提供的 Python、证书源文件声明。
